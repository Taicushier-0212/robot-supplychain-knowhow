# 成本与交期

从图纸抽出哪些项在烧钱、怎么挑战报价，见 [采购看图与估价](../playbooks/drawing-quote.md)。

## VAVE 是什么

**VA/VE**（常写成 **VAVE**）= **Value Analysis / Value Engineering**，价值分析 / 价值工程。一句话：在 **功能不降（或明确可接受）** 的前提下，拿掉多余成本。

| | **VA 价值分析** | **VE 价值工程** |
|---|---|---|
| 时机 | 多半针对 **已经在做 / 已量产** 的件 | 多半在 **设计阶段** 就把成本做进去 |
| 问法 | 这功能还要吗？用更便宜的方式能否同等实现？ | 需求一出来就拆功能与成本，避免后期大改 |
| 供应链角色 | 拉厂谈替代料、工艺、包装、MOQ；推动改图走 ECN | 早期参与选型与 DFM，避免独家贵方案锁死 |

口头公式：

```text
价值 ≈ 功能 / 成本
```

功能不变、成本下降 → 价值升；成本微升但功能/可靠性明显升，有时也算过——**要书面接受，不能口头「差不多」**。

### 机器人供应链里常见 VAVE 动作

- 材料：6061 能否顶不必上的 7075；板厚、表面处理降一档是否仍满足。  
- 公差：非配合面从特殊公差回到未注；见 [看图与估价](../playbooks/drawing-quote.md)、[工艺工程](./process-engineering.md)。  
- 工艺：能钣金不CNC；能标准件不图纸件；热处理/阳极是否过剩。  
- 供应：第二来源、国产替代、合并料号降 MOQ。  
- 包装与物流：过度防护降级（精密件除外）。  

### 红线（VAVE 不是砍规格私了）

- 不冻结就用目标价倒逼，违反 [原则](./principles.md) 第 2 条。  
- 改材料、公差、表面处理 = **升版 / ECN**，旧 RFQ 作废；IQC 按新版检。  
- 安全、高压电气、承力、认证相关：**不做「先便宜装上再补」**。  
- 降本提案要写：改什么、省多少、风险、谁拍板、哪一版图生效。  

初期人少：采购 + 结构/电气 + 工艺工程开短会即可，不必单立 VAVE 部门；结论进图纸版本，不进聊天记录当合同。

## 成本怎么拆

不要只记「一颗多少钱」。至少拆成：

| 块 | 问什么 |
|---|---|
| 材料 | 牌号、厚度、替代是否允许 |
| 加工 | 机床类型、装夹次数、公差带 |
| 后处理 | 阳极 / 喷涂 / 热处理是否外发二次 |
| 样品费 | 是否可抵批量；模具 / 夹具谁出 |
| 物流与包装 | 电池、精密件是否要特殊包装 |
| 账期 | 含税口径、预付比例、质保金 |

## 交期倒排

```text
需要上线日
  − 装配缓冲
  − 物流
  − 加工 / 生产周期
  − 打样 + FAI（若必须）
  − 询价窗口
  = 最晚冻结图纸日（G0/G1）
```

长周期器件（伺服芯片、特定电芯、进口编码器、谐波）在 **G0 就要标红**，不要等结构件图纸齐了才发现电子要 16 周。

## 滚动库存

滚动库存是按周期往前看的一段覆盖，不是仓库里永远放着同一个数。

每个计划周期（口头常按周）做一次：

```text
在手合格 + 在途 − 已分配 ≥ 未来 N 周（或 N 套）的需求
```

用掉的部分在下一周期补上，窗口跟着时间往前滚。所以在手数量会变，要盖住的「未来多久」不变。不合格、待检的不算在手。

它和旁边几个词不是一回事：

| 词 | 是什么 |
|---|---|
| **滚动库存** | 在手加在途，始终盖住未来 N 周或 N 套 |
| **安全库存** | 为跳票、不良多出来的最低垫层，可以含在这 N 周里，单独写明 |
| **按套买齐** | 试点几套就买几套，用完不自动补 |
| **滚动盘点** | 循环去数库存，是盘点方法，不产生备料 |
| **寄售** | 货在谁的仓库、账在谁身上，和滚不滚动无关 |

样机、图纸还在升版的结构件，默认按套买，不建滚动库存。升一版，在手和在途都可能报废。适合滚动的是规格已经冻住、会连续消耗的料：紧固件、线材、包材，以及交期很长但型号不再改的芯片、电芯、编码器。

长周期料的滚动要在交期之前就发出 PO。每周重算一次、却在缺料当周才下单，窗口滚了，货仍要等十几周。N 是几周，按该料交期加装配缓冲来定，不按「仓库看起来满」定。

## 常见幻觉

- 「样品 7 天」不含排队、不含表面处理外发。
- 改一个倒角等于新交期，不是插队。
- 含税 / 未税混比，看起来便宜 13%。
