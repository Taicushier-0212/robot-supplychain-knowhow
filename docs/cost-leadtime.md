# 成本与交期

## 成本怎么拆

不要只记「一颗多少钱」。至少拆成：

| 块 | 问什么 |
|---|---|
| 材料 | 牌号、厚度、替代是否允许 |
| 加工 | 机床类型、装夹次数、公差带 |
| 后处理 | 阳极 / 喷涂 / 热处理是否外发二次 |
| 样品费 | 是否可抵批量；模具 / 夹具谁出 |
| 物流与包装 | 电池、精密件是否要特殊包装 |
| 账期 | 含税口径、预付比例、质保金 |

## 交期倒排

```text
需要上线日
  − 装配缓冲
  − 物流
  − 加工 / 生产周期
  − 打样 + FAI（若必须）
  − 询价窗口
  = 最晚冻结图纸日（G0/G1）
```

长周期器件（伺服芯片、特定电芯、进口编码器、谐波）在 **G0 就要标红**，不要等结构件图纸齐了才发现电子要 16 周。

## 滚动库存

滚动库存是按周期往前看的一段覆盖，不是仓库里永远放着同一个数。

每个计划周期（口头常按周）做一次：

```text
在手合格 + 在途 − 已分配 ≥ 未来 N 周（或 N 套）的需求
```

用掉的部分在下一周期补上，窗口跟着时间往前滚。所以在手数量会变，要盖住的「未来多久」不变。不合格、待检的不算在手。

它和旁边几个词不是一回事：

| 词 | 是什么 |
|---|---|
| **滚动库存** | 在手加在途，始终盖住未来 N 周或 N 套 |
| **安全库存** | 为跳票、不良多出来的最低垫层，可以含在这 N 周里，单独写明 |
| **按套买齐** | 试点几套就买几套，用完不自动补 |
| **滚动盘点** | 循环去数库存，是盘点方法，不产生备料 |
| **寄售** | 货在谁的仓库、账在谁身上，和滚不滚动无关 |

样机、图纸还在升版的结构件，默认按套买，不建滚动库存。升一版，在手和在途都可能报废。适合滚动的是规格已经冻住、会连续消耗的料：紧固件、线材、包材，以及交期很长但型号不再改的芯片、电芯、编码器。

长周期料的滚动要在交期之前就发出 PO。每周重算一次、却在缺料当周才下单，窗口滚了，货仍要等十几周。N 是几周，按该料交期加装配缓冲来定，不按「仓库看起来满」定。

## 常见幻觉

- 「样品 7 天」不含排队、不含表面处理外发。
- 改一个倒角等于新交期，不是插队。
- 含税 / 未税混比，看起来便宜 13%。
