# G0–G5 放行门

同一套 Gate 适用于关节模组、机加、电子、电池等所有大类；细节差在门类 knowhow 里，门本身不跳。和 SOP / RACI / 授权 / 异常复盘怎么拼成一条链，见 [最小闭环](./ops-loop.md)。

```text
G0 需求/SKU 冻结
  → G1 申购 PR（图纸版本锁死）
    → 寻源短名单 / 供应商准入
      → G2 询价 RFQ + 打样 / 首件 FAI
        → 比价选定（成本·交期·质量·账期）
          → G3 下单 PO + 跟单
            → G4 到货 IQC / 入库
              → 发料（研发/装配）
                → 异常 NCR / 退换
                  → G5 关单、台账、供应商评分
```

| Gate | 放行条件 | 卡住时禁止 |
|---|---|---|
| **G0** | 首发可买范围、料号/规格一句话、试点数量写清 | 散单采购、无料号申购 |
| **G1** | PR 审核通过；料号/版本与图纸一致 | 对外询价、改图后沿用旧报价 |
| **G2** | 样品或首件判定 Pass / Conditional | 必须打样的料直接量产下单 |
| **G3** | PO 含税口径、交期、账期、收货地址齐全 | 口头加单、微信截图当合同 |
| **G4** | IQC 勾选完成并归档 | 不合格品上线/发给装配 |
| **G5** | 数量对账、质量结论、交期记录回写供应商 | 同一问题重复踩、无复盘 |

## 单据状态机

```text
PR:  草稿 → 已审核 → 询价中 → 已下单 → 已关闭
RFQ: 已发出 → 已回价 → 已选定 / 已作废
PO:  已下单 → 跟单中 → 部分到货 → 已到齐 → 已关闭
IQC: 待检 → Pass / Conditional / Fail
NCR: 打开 → 处理中 → 关闭（换货/让步/报废）
```

作废必须留原因（升版、需求取消、供应商退出），不要删历史。

## 建议编号

| 对象 | 编号 |
|---|---|
| 申购 | `PR-YYYYMMDD-001` |
| 询价 | `RFQ-YYYYMMDD-001` |
| 采购单 | `PO-YYYYMMDD-001` |
| 首件 | `FAI-<PO号>-<料号>` |
| 来料检 | `IQC-<PO号>` |
| 不合格 | `NCR-YYYYMMDD-001` |

单号只增不改。作废在文件头标明 `void` 与原因。
