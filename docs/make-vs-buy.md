# 自制 vs 外购

早期人形样机不要默认「能买就买」或「能搓就搓」。按下表先分类，再进 G0。图能不能稳定做出来、试产怎么收敛，见 [工艺工程（DFM 等）](./process-engineering.md)。

| 大类 | 默认策略 | 原因 |
|---|---|---|
| 关节模组（成套） | **外购 ODM**，规格自控 | 价值最高、交期最长、一致性难手搓 |
| 减速机 / 无框电机 / 编码器 / 驱动器 | 外购；集成时跟模组走 | 拆开自组只在接口或交期被卡时 |
| 结构件（CNC / 钣金 / 型材） | **外协**；图纸与公差自控 | 产能在厂外，改图成本在自己 |
| 法兰 / 连接件 / 标准件 | COTS 或图纸件外协 | 可跳过打样，不可跳过点数与规格核对 |
| 型材 Link | 外购型材 + 二次加工 | 规格与孔位必须冻在图纸 |
| PCB / SMT | 外发打样 → 小批 | 长周期器件在 G0 标出 |
| 线束 | 外发，按图纸与接头型号验收 | 禁止「看着能插」过检 |
| 电池 PACK | 外购；电芯品牌与保护策略写死 | 运输仓储单独规则 |
| 3D 打印 | 仅工装 / 验证件 | 不默认为承力结构量产路径 |
| 注塑 / 压铸 | 小批前不轻易开模 | 开模前必须冻结外观与装配接口 |
| 灵巧手 | 外购整手或关节套件 | 自制仅在差异化明确时 |

## 必须打样 vs 可直接小批

写进 G0，不要临下单再争：

- **必须打样**：承力结构、关节模组、电池 PACK、定制线束、新开模具件  
- **可直接小批**：目录标准件、明确品牌替代规则的轴承/紧固件、重复下过且 IQC 稳定的 COTS  

## 试点数量怎么算

```text
采购量 = 单套用量 × 采购套数 × (1 + 损耗预留)
```

结构件损耗预留建议 ≥10%；电子按最小包装取整。  
「先买 1 个试试」可以，但要标明这是样品，不是试点齐套。
