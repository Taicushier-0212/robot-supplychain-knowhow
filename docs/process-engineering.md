# 工艺工程（研发 ↔ 量产）

研发把「能做出一台」画出来；量产要「每一台都差不多、能检、能修、交得起」。中间这一截叫 **工艺工程 / NPI / 制造工程**——席位名可以叫 PE、ME、工艺、试产，事情不能空。

人不在编制里时：结构/电气各自兼 DFM，供应链 SQE 兼供应商工艺对话；**会签和工艺文件仍要有**，不能只靠微信改图。

和买料门的关系：工艺工程不替代 [G0–G5](./gates.md)，但 G0/G1 的可制造性、G2 首件、量产切换，很多卡点在他们手上。总图见 [最小闭环](./ops-loop.md)。

## 一句话职责

```text
把设计意图变成可重复制造的工艺与检验：
  图能做（DFM）→ 能装（DFA）→ 能测（DFT）→ 能供（供应/工艺窗口）
  → 试产收敛 → 量产工艺冻结 → 变更受控
```

## DFx 要管什么（含 DFM）

口头常说「做个 DFM」——其实是一簇检查，别混成一句「看着好做」。

| 缩写 | 问什么 | 机器人里常见落点 |
|---|---|---|
| **DFM** Design for Manufacturability | 零件本身厂里做得出来、做得稳吗 | 机加公差是否落在标准工艺；钣金折弯半径/孔边距；压铸/注塑拔模与壁厚；PCB 线宽线距/钢网/拼板；齿轮热处理与磨齿顺序 |
| **DFA** Design for Assembly | 人/线装得快、装不错吗 | 关节法兰螺钉可达；线束出线方向；防呆与极性；少用双侧同时对位；重件有吊装/支撑点 |
| **DFT** Design for Test | 产线/IQC 测得到吗 | 测试点别被三防盖死；ICT/FT 夹具空间；编码器零位与标定口；烧录口量产还在不在壳里 |
| **DFS** Design for Service | 坏了换得了吗 | 内驱维修路径；密封件可拆；易损件（轴承、脂、接插件）可单独换 |
| **DFC / 成本** | 工艺窗口会不会把单价打飞 | 非必要的形位、镜面、非标齿形、独家表面处理；见 [成本与交期](./cost-leadtime.md) |
| **DFP / 采购** | 料找得到、有第二来源吗 | 长周期芯片、独家连接器、非标轴承；P0 两家可询见 [原则](./principles.md) |

样机阶段可以先过 **DFM + DFA + DFT** 三张清单；DFS/成本在进小批前补齐。

## DFMEA 是什么

**DFMEA**（Design FMEA）是设计失效模式与影响分析。在图纸冻结、开模之前，把「这个设计会怎么失效、失效之后关节或整机会怎样、现在靠什么发现、要不要改设计」写成一张表。它不是来料检验，也不是供应商的 [8D](../playbooks/ncr.md)。8D 是已经做错了以后的纠正；DFMEA 是还没做错时先改设计。

同一族里还有 **PFMEA**（过程 FMEA）：问的是制造和装配过程会怎么做错，例如热处理漏回火、阳极没保护轴承孔、贴片极性反。DFMEA 改的是图和规格，PFMEA 改的是工艺、检具和作业。口头只说「做个 FMEA」，要问清是设计还是过程。

一张 DFMEA 至少这些列：

| 列 | 写什么 |
|---|---|
| 功能 | 这个结构、电路或接口要保证什么 |
| 失效模式 | 它怎么达不到，例如轴承室阳极后过盈变紧、单编看不到回差、母线电容吃不住再生 |
| 影响 | 对上一级的后果：装不上、掉电砸膝、掉帧。安全、承力、高压按 [L3](./quality.md) 写，不写成「体验不好」 |
| 原因 | 设计上的原因，不是「供应商粗心」 |
| 现有控制 | 已经写进图里的防错、冗余、检规。还没做的检测不要算进去 |
| 措施 | 改图、加冗余、改检规。负责人、完成节点写上 |

严重度 S、发生度 O、探测度 D 常见各打 1–10。老表用 **RPN = S×O×D**，再卡一个分数。现行 AIAG-VDA 用措施优先级 **AP**（高 / 中 / 低），高优先级先改，不靠一个全厂统一的 RPN 门槛。打分口径在表头写明用哪一版，两版不要混在同一列里比大小。

谁写：设计负责人（结构、电气或关节）主笔。工艺工程和 QE 看可制造、可检测。产品接受留下来的风险。供应链不代填失效模式；和买料有关的行（独家料、长周期、无法检验）由计划和 SQE 补进原因和措施。

进 G1 之前，承力结构、关节接口、驱动和断电抱闸、电池和高压，要有 DFMEA 里对应的一行，并且 L3 的措施不是「全检」。全检是 PFMEA 里的探测，设计本身仍会失效。样机可以只做这些关键件，不必第一天铺成整机几百行。

## 阶段要做什么

| 阶段 | 工艺工程主产出 | 和谁咬合 |
|---|---|---|
| **概念 / 详细设计** | DFx 评审记录；不可制造项打回改图 | 结构 / 电气 / 关节；产品拍板是否改需求 |
| **G0–G1** | 关键件工艺路线一句话（机加→热处理→磨；SMT→AOI→ICT…）；检具/夹具是否要开 | 计划标长周期；采购知工艺窗口 |
| **打样 / G2** | 工艺卡草稿、检验计划（IPQC 要点）、跟首件 | [首件 FAI](../playbooks/first-article.md)；SQE 看厂能力 |
| **试产（工程样 → 小批）** | 试产问题单；节拍与不良归类；工艺参数窗口 | 装配 / 测试；IQC 检规对齐 |
| **量产切换** | **工艺文件冻结**（与图纸版本绑定）；培训与产线放行 | 制造 / ODM；供应链锁量产 PO |
| **量产后** | 工程变更（ECN）工艺影响评估；重复不良改工艺或改图 | [NCR / 8D](../playbooks/ncr.md)；升版见原则第 5 条 |

## 日常清单（可兼岗也要勾）

**设计侧**

- [ ] 出正式图前做过 DFM/DFA/DFT（至少关键件：承力结构、关节接口、驱动板、线束）
- [ ] 上述关键件有 DFMEA：L3 有改设计或冗余，不把「全检」当成设计措施
- [ ] 公差：能按标准工艺做的不要按实验室极限写；形位与基准可测
- [ ] 材料与表面处理：牌号/状态/膜厚可外协，且和装配（导电、密封、胶）不打架
- [ ] 电子：叠层与阻抗按目标板厂；检测链 SPI/AOI/X-Ray/ICT/FT 哪些要做写进会签（见 [PCB](../knowhow/03-electronics/pcb.md)）

**试产侧**

- [ ] 工艺路线、关键工序参数、换型注意点有书面版（可以简，不能只在师傅脑子里）
- [ ] 工装 / 钢网 / 针床 / 标定工装的版本与硬件版本绑定
- [ ] 首件与小批不良按：设计 / 来料 / 工艺 / 作业 四分，不默认「厂不行」
- [ ] 样品产线 ≠ 量产产线时，切换前重做首件或小批确认

**量产与变更**

- [ ] 量产工艺版本号；和图纸、BOM、检规同一套版本语言
- [ ] 改一个孔、换一家表面处理、换 SMT 钢网：走 ECN，评估在制与库存，旧 RFQ/旧单价默认作废
- [ ] 供应商改工艺（模具、分供方、热处理炉）：等同变更，SQE + 工艺工程知情，必要时重 FAI

## 和别的角色怎么分

| 事 | 工艺工程 | 不是他们的 |
|---|---|---|
| 图能不能做、怎么做更稳 | R（DFM 意见） | 不替产品改需求目标 |
| 供应商工艺能力对话 | C / 与 SQE 搭 | 商务谈判、下 PO 是供应链 |
| 来料 Pass/Fail | C（检规输入） | 判定权在 [IQC](./roles.md) |
| 装配作业指导 | R 或与制造共写 | 不私下让步不合格品 |
| 规格冻结拍板 | C | A 在结构/电气/关节/产品，见 [RACI](./raci.md) |

初期一人兼：结构兼机加 DFM，电气兼 SMT/DFT，SQE 兼外协工艺——**评审记录和工艺版本仍要留下**。

## 冻结（进小批前）

- [ ] 关键件 DFM/DFA/DFT 结论（Pass 或「已改图」）
- [ ] 工艺路线与检验计划版本
- [ ] 工装 / 钢网 / 夹具清单与版本
- [ ] 试产开放问题单：关闭或限条件放行（谁签的）
- [ ] 量产切换条件：连续小批不良阈值 / 首件 Pass / 检规对齐（写数字，不写「差不多」）
- [ ] ECN 入口：谁提、谁评工艺影响、谁通知在制 PO

## 已知坑

- 样机能装 ≠ 可量产：全靠钳工修配，DFM 从没做过。
- 只做 DFM 不做 DFT：板贴完测不了，三防盖住测试点。
- 公差按「设计理想」写，厂报价按非标，交期和单价一起炸。
- 试产问题只改作业口诀，不改图也不改检规，换一批人又复发。
- 量产了还在微信口头改工艺参数，出了 NCR 对不上版本。
- 供应商悄悄换热处理或钢网，当来料问题打转——实为未受控的工艺变更。
- 开模/压铸前接口未冻，模具改不动，DFM 变成事后检讨。
