# 质量口径

判定能不能发料用下面三种结果；严重度另标 **L1 / L2 / L3**，见 [最小闭环](./ops-loop.md)。总流程与授权仍走 G0–G5 和 [RACI](./raci.md)。席位日常动作见 [职位](./roles.md)。

## QC / QE / QSM（以及和本仓席位怎么对）

招聘和组织图上常见这三个缩写；**各司叫法不完全统一**，谈职责时要问清管来料、管过程、还是管体系。本仓落地席位主要是 **IQC** 和 **SQE**。

| 缩写 | 常见全称 | 一句话 | 典型干什么 | 本仓落点 |
|---|---|---|---|---|
| **QC** | Quality Control 质量控制 | **按标准检实物** | 来料 / 制程 / 出货检验，开不合格，留下记录 | 主对应 [IQC](./roles.md)；产线制程检口头 IPQC，出货 OQC |
| **QE** | Quality Engineer 质量工程师 | **把质量做成可重复的工程** | 检规与控制计划、FMEA、试产质量、不良分析、改检具/改流程；对内产品或过程 | 与工艺工程、试产咬合；对供应商时常由 **SQE** 承担 |
| **SQE** | Supplier Quality Engineer | **管供应商能不能稳定做对** | 准入、首件、供应商端纠正与 8D | 本仓已单列 [SQE](./roles.md) |
| **QSM** | 多义，上岗先问全称 | 多半偏 **体系或质量+供应管理** | 见下 | 初期常由供应链负责人兼，不单独立岗 |

**QSM** 口头至少三种，不要默认同一种人：

| 对方说的 QSM | 常指 | 和 QC/QE 的差别 |
|---|---|---|
| Quality System Manager / Management | 质量体系（ISO、程序文件、内审、管理评审） | 管「规则在不在、审不审得过」，不天天判来料 Pass |
| Quality & Supplier Management | 质量 + 供应商质量一摊 | 更像 SQE + 部分采购质量策略 |
| Quality Supervisor / Manager（个别厂乱缩写） | 质量主管 | 带 QC 班组，职责看岗位说明书 |

和本仓铁律的关系：

- **QC / IQC**：G4 判定权；不批准让步发料。  
- **QE**：把检什么、怎么检写进检规与试产；不替代 IQC 在来料单上签字放行。  
- **SQE**：厂侧闭环；首件 Pass ≠ 本批 IQC Pass。  
- **QSM（体系）**：程序和记录能不能支撑追溯与审核；具体一批评定仍归 IQC。

人少时常见兼法：QC 兼 IQC；QE 兼 SQE（记录仍要分开）；QSM 由负责人兼体系动作。兼岗不兼丢检查项，见 [职位 · 初期兼岗](./roles.md)。

## 三种判定

| 结果 | 含义 | 下一步 |
|---|---|---|
| Pass | 对照 PO + 图纸可发料 | 入库 |
| Conditional | 缺陷不影响安全 / 接口，限本批次 | 供应链主责 + 使用方会签后才能发 |
| Fail | 不能用或责任未清 | 隔离 + NCR + 通知供应商 |

现场争议：检测主责先判定 → Fail 开 NCR → Conditional 必须会签 → 仍僵持升级到产品 / 供应链共管。

## 异常分级（与判定同时写）

| 级 | 含义 | 和判定的关系 |
|---|---|---|
| **L1** | 不影响安全与接口 | 常对应 Conditional 或挑修后 Pass |
| **L2** | 功能 / 接口 / 关键尺寸不过 | 对应 Fail；开 NCR |
| **L3** | 安全、高压电气、承力、危货合规 | 对应 Fail；禁止口头让步；负责人知情 |

IQC 出结论时建议等级；供应链按级组织让步或退换。细则与复盘关门条件见 [最小闭环](./ops-loop.md)、[NCR](../playbooks/ncr.md)。

## 追溯最低线

发到哪一套样机，要能回溯：**厂商 + PO + 批次 / 日期码**。余料退库，禁止个人抽屉库存。

## 让步红线

安全、高压电气、承力结构件：**不允许口头让步。**
