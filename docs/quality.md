# 质量口径

判定能不能发料用下面三种结果；严重度另标 **L1 / L2 / L3**，见 [最小闭环](./ops-loop.md)。总流程与授权仍走 G0–G5 和 [RACI](./raci.md)。

## 三种判定

| 结果 | 含义 | 下一步 |
|---|---|---|
| Pass | 对照 PO + 图纸可发料 | 入库 |
| Conditional | 缺陷不影响安全 / 接口，限本批次 | 供应链主责 + 使用方会签后才能发 |
| Fail | 不能用或责任未清 | 隔离 + NCR + 通知供应商 |

现场争议：检测主责先判定 → Fail 开 NCR → Conditional 必须会签 → 仍僵持升级到产品 / 供应链共管。

## 异常分级（与判定同时写）

| 级 | 含义 | 和判定的关系 |
|---|---|---|
| **L1** | 不影响安全与接口 | 常对应 Conditional 或挑修后 Pass |
| **L2** | 功能 / 接口 / 关键尺寸不过 | 对应 Fail；开 NCR |
| **L3** | 安全、高压电气、承力、危货合规 | 对应 Fail；禁止口头让步；负责人知情 |

IQC 出结论时建议等级；供应链按级组织让步或退换。细则与复盘关门条件见 [最小闭环](./ops-loop.md)、[NCR](../playbooks/ncr.md)。

## 追溯最低线

发到哪一套样机，要能回溯：**厂商 + PO + 批次 / 日期码**。余料退库，禁止个人抽屉库存。

## 让步红线

安全、高压电气、承力结构件：**不允许口头让步。**
