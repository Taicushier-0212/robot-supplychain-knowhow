# RACI（初期编制口径）

席位可以空缺，责任不能空缺。空缺时按表下「代签规则」写进该 PO。供应链内部每个位子做什么，见 [职位](./roles.md)。让步/下单/关 NCR 等决策权汇总见 [最小闭环 · 授权矩阵](./ops-loop.md#授权矩阵初期)。

| 活动 | 产品 | 供应链 | 电气 | 结构 | IQC | 关节 | 工艺工程 |
|---|---|---|---|---|---|---|---|
| SKU / 可买范围冻结 | A | R | C | C | I | C | I |
| 机加 PR 审核 | C | R | I | A | I | I | C（DFM） |
| 寻源 / 商务 / PO | I | R | I | C | I | C | I |
| 关节规格与 ODM 技术 | C | C | C | I | I | R | C |
| PCB / 电子 BOM | I | C | R | I | I | I | C（DFT/SMT） |
| DFx / 试产放行 | C | I | C | C | I | C | R |
| 来料检测 | I | C | C（电） | C | R | C（模组） | C（检规） |
| Conditional 让步 | C | R | C | A | C | C | C |
| 装配领料 | I | C | I | A | C | I | C |

工艺工程空缺时：机加 DFM 由结构兼，板级 DFT/SMT 由电气兼，外协工艺对话由 SQE 兼；评审记录仍要留。细则见 [工艺工程](./process-engineering.md)。

R = 执行主责 · A = 拍板 · C = 会签 · I = 知情。

**代签规则**

- 结构相关空缺：产品 + 供应链代  
- 关节空缺：产品 + 电气，供应链管商务与备份来源  
- IQC 未到岗：供应链指定临时代检人，姓名写进该 PO  
- 工艺工程未到岗：结构 + 电气按域兼 DFx，SQE 兼供应商工艺；试产放行仍要有书面结论  


## 争议升级

```text
现场争议（尺寸/功能）
  → IQC 先判定 Pass / Fail / 建议 Conditional
    → Fail：开 NCR，通知供应商，隔离实物
    → Conditional：供应链 + 使用方会签后才能发料
      → 仍僵持：产品与供应链共管制造决策；涉及模组电气则拉电气
```
