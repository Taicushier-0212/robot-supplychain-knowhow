# 供应链职位

席位可以一人兼，事情不能兼丢。下面按 [G0–G5](./gates.md) 写每个位子该做什么。活动谁拍板、空缺谁代签，见 [RACI](./raci.md)。

一人兼多岗时，这一单谁在代哪一岗，写在该 PR / PO 上。不要只记在微信里。

## 总览

| 职位 | 主门 | 一句话 |
|---|---|---|
| 供应链负责人 | 全门 | 把门守住，缺的位子安排代签，不替别人改规格 |
| 计划 | G0–G1、齐套 | 算要买多少、哪天必须冻结、哪天会缺料 |
| 采购 | G1–G3 | 找厂、询价、比价、把商务条件写进 PO |
| 跟单 | G3–G4 | 追在途节点，逾期往上抛，不私下改交期和数量 |
| SQE | 准入、首件、NCR | 看这家厂能不能做，出了问题向厂要纠正 |
| IQC | G4 | 按 PO 和图纸判定 Pass / Conditional / Fail |
| 仓储 | G4 之后 | 未检隔离，只按检验结论收发，账和实物一致 |

组织图上的 **QC / QE / QSM** 是常见质量缩写，和上表 IQC、SQE 怎么对应，见 [质量口径 · QC/QE/QSM](./quality.md#qc--qe--qsm以及和本仓席位怎么对)。

物流和报关初期挂在跟单或仓储上，不单独立岗。进口件、电池运输变成每周的日常之后再拆。

研发与量产之间的 **工艺工程**（DFM/DFA/DFT、试产、工艺冻结）不在上表供应链席位里，但和 SQE/IQC/采购咬合；口径见 [工艺工程](./process-engineering.md)。

## 供应链负责人

对整条链的放行负责：G0 没冻不让散单，G4 没检不让发料，不合格没有 NCR 不让让步。见 [原则](./principles.md)。

日常做这些：

- 看本周卡在哪一道门，缺的决策找该拍板的人，不自己把结构图或电气规格签掉。
- 独家料、跳票、危货按 [风险](./risk.md) 单列，备份来源或安全库存要有下文。
- 席位空缺时按 [RACI 代签规则](./raci.md) 指定代签人，姓名写进该 PO。
- 关单时看交期、质量、账是否回到台账，同一坑没有复盘就不算 G5 完成。

不接这些：

- 替结构审核机加图纸，替关节改模组规格，替电气改 BOM。
- 用目标单价倒逼还没冻结的规格。
- 在 IQC 判 Fail 之后直接让装配先用。

## 计划

把「要装几套」变成「每种料买多少、最晚哪天必须下单」。交期倒排见 [成本与交期](./cost-leadtime.md)。

日常做这些：

- 数量按单套用量 × 采购套数，加上约定的损耗。结构件和电子的预留比例分开写，不拍一个总数。
- 长周期料（芯片、电芯、编码器、谐波这一类）在 G0 标出来，不等结构图齐了才发现要十几周。
- 齐套：缺哪一颗会卡住装配，单独列，不跟普通标准件混在同一条「在途」里。
- 规格已冻住、会连续消耗的料，才按 [滚动库存](./cost-leadtime.md) 补；图纸还在升版的结构件按套买。
- 图纸升版后，旧需求数量和旧交期默认作废，重排再给采购。

不接这些：

- 为了赶上线日，自己改材料、公差或版本。
- 把供应商口头的「样品 7 天」当成上线日。样品周期不含排队和表面处理外发。

产出是申购数量、要货日、缺料清单。采购单上的价格和厂商不是计划填的。

## 采购

从已审核的 PR 走到可以下的 PO。寻源和询价步骤见 [寻源](../playbooks/sourcing.md)、[询价](../playbooks/rfq.md)。看图抓成本项、按图拆价见 [采购看图与估价](../playbooks/drawing-quote.md)。

日常做这些：

- 按元器件页的冻结清单找厂。P0 至少两家可询；独家要写明原因和备份，不藏在聊天记录里。
- 发 RFQ 前先读图框版本、材料状态、表面/热处理、紧公差与形位；要求厂按块回价，不只丢一个总数。
- 书面报价同时看含税口径、MOQ、交期、样品费、账期、不良和返修。不只比单价。
- PO 写清料号、版本、数量、含税价、交期、账期、收货地址。升版后的图用新报价，不用上周那张。
- 未准入的厂可以要意向价，不下正式 PO。名录和电话写在作业仓库，不写进本仓库。

不接这些：

- 图纸没冻、PR 没审核就对外当正式询价。
- 口头加单、微信截图当合同。对账只认 PO 或书面变更。
- 自己判定来料能不能用。

## 跟单

PO 发出之后，把「加工到哪了」写成节点，而不是一句「在做了」。

节点至少四档：材料到位、加工中、已出货、在途。逾期在到货日之前报给计划和负责人，不拿到货当天再说。

日常做这些：

- 每张在途 PO 有一个下一节点和下一次要问的日期。
- 供应商要改交期、改数量、改版本，回到采购做书面变更。跟单不直接答应。
- 到货信息（运单、箱数、预计到仓时间）交给仓储和 IQC，让检验排得上。

不接这些：

- 「先收下来用着」这种让步。让步只有 Conditional 会签之后才能发料。
- 用催货代替缺料判断。催不回来的料要回到计划重排上线，而不是一直标黄。

采购和跟单可以由同一人兼。兼的时候，催货记录和 PO 变更仍然是两件事。

## SQE

看供应商能不能稳定做出冻结的规格，以及出了不合格怎么纠正。准入见 [供应商准入](../playbooks/supplier-qualification.md)，首件见 [首件](../playbooks/first-article.md)，闭环见 [不合格闭环](../playbooks/ncr.md)。

日常做这些：

- 准入看能力：这类件的工艺、检验手段、开票和返修，不是只看报价低。
- 必须打样的料，首件结论是 Pass 或书面 Conditional 之后，采购才能下量产 PO。
- Fail 或重复不良：向厂要原因、纠正和影响批次。重复、安全、流到装配的，要 [8D](../playbooks/ncr.md)。关闭 NCR 要有证据，不是供应商回一句「已经注意」。
- 样品和量产若换了产线、模具或关键分供方，首件要重做。

不接这些：

- 在来料单上签字放行。那是 IQC 的判定。
- 用一次样品合格代替之后每一批的来料检验。

SQE 和 IQC 初期可以同一人。首件记录和每一批的 IQC 记录仍然分开存。同一个人不能用「上次首件过了」当作这一批的 Pass。

## IQC

到货后对照 PO 和冻结的图纸或规格做判定。步骤见 [来料检验](../playbooks/incoming-inspection.md)，三种结果见 [质量口径](./quality.md)。

| 结果 | IQC 做什么 |
|---|---|
| Pass | 在检验记录上关闭，通知仓储可以入库 |
| Conditional | 写清缺陷和限用批次，交给供应链和使用方会签；会签完成前不发料 |
| Fail | 隔离实物，开 NCR，通知采购或 SQE 去找供应商 |

日常做这些：

- 未检品和已检品分开摆。记录能追溯到厂商、PO、批次或日期码。
- 电的项目拉电气，模组拉关节，尺寸争议拉结构。IQC 先给出 Pass / Fail / 建议 Conditional，不把「我看着行」当成结论。
- 安全、高压电气、承力结构件不做口头让步。

不接这些：

- 自己批准让步并发料。Conditional 的会签不在 IQC 一个人身上。
- 替采购改 PO 数量来「把不合格变成合格」。短装、错版是差异，不是改写标准。

IQC 未到岗时，由供应链负责人指定临时代检人，姓名写进该 PO。代检人仍要留下和正式 IQC 一样的记录。

## 仓储

管实物和账：收进来、隔离开、按结论入库、按领料发出去。

日常做这些：

- 到货先收进待检，不拆开就送装配、不放进线边。
- 只有 IQC 的 Pass，或已经会签的 Conditional，才能上架和发料。Conditional 的料标记批次，发到哪一套要能查回来。
- 账实一致：PO 数量、入库数量、领用数量、退库数量对得上。余料退库，不进个人抽屉。
- 电池和精密件按要求的包装与库区放，不和普通机加件堆在一起。

不接这些：

- 凭外观或供应商的出货单放行。
- 为了齐套把 Fail 的箱子先发给装配，事后再补单。

## 容易混的边界

| 两件事 | 分开的办法 |
|---|---|
| 计划 vs 采购 | 计划给数量和要货日；采购给厂商、价格和 PO。计划不改规格，采购不改「要装几套」 |
| 采购 vs 跟单 | 采购改书面条款；跟单只报节点。催货不是变更 |
| SQE vs IQC | SQE 管这家厂和首件；IQC 管这一批到货。首件 Pass 不等于这一批 Pass |
| IQC vs 仓储 | IQC 下结论；仓储按结论搬箱子。仓储不改结论 |
| 供应链 vs 产品 / 结构 / 电气 | 供应链守门和商务；规格谁冻结，谁对那一栏负责。见 [RACI](./raci.md) |

## 初期可以怎么兼

人少时按下面合并，检查项不合并：

- 负责人兼计划：数量和长周期清单仍要写出来，不能只在周会上说。
- 采购兼跟单：PO 变更和在途节点分两处记。
- SQE 兼 IQC：首件和来料各留一张记录。
- 仓储未到岗：指定收货人，待检区仍然要有，不能快递拆开直接进实验室。
