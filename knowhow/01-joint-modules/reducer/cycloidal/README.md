# 摆线减速机（含 RV）

**大类：** [关节模组](../../README.md) · **小类：** [减速机](../README.md)

针齿和摆线齿廓啮合，多齿同时接触，刚度高、抗冲击。工业机器人基座和重载臂上的默认件叫 **RV**（Rotary Vector 已成通称）：**渐开线行星前级 + 摆线主减速**，曲柄轴两端支撑。单级针摆、人形轻量化摆线是同一族，不是同一张样本。

| 页 | 讲什么 |
|---|---|
| [结构与形态](./structure.md) | 纯针摆 K-H-V vs RV 两级封闭；双盘、曲柄轴、中空 |
| [额定与寿命](./ratings.md) | 三档扭矩、刚度、弯矩、回差；寿命看轴承不是柔轮 |
| [装配与润滑](./assembly.md) | 针齿成套、主轴承预紧、脂量、安装方向 |

髋、踝、有时膝：冲击和弯矩大，谐波柔轮吃不住时看摆线。腕、肘要薄要中空，不要拿工业 RV 硬塞。

## 三种不要混下单

| | **工业 RV** | **纯针摆**（单级） | **人形轻量化摆线** |
|---|---|---|---|
| 结构 | 行星前级 + 双摆线盘 + 曲柄双支撑 | 偏心轴 + 针齿，偏心常悬臂 | 针摆或缩小 RV，铝壳、少针、减壁 |
| 刚度 / 抗冲 | 工业六轴默认 | 低于 RV，径向力难抵消 | 介于谐波和工业 RV，以该型号表为准 |
| 重量 / 厚 | 小规格也常数公斤、轴向厚 | 可更扁，看怎么做壳 | 为髋膝减重，**不能拿工业 RV 重量去比** |
| 交期 / 成本 | 成熟、重载档贵 | 看厂家 | 人形定制多，规格绑定模组 |

BOM 只写「摆线」会把工业 RV 装进人形髋。类型、重量、厚度必须和占位一起冻。

## 相对行星的优劣

对照的是关节里常见的 **多级 NGW 渐开线行星**，不是平行轴齿轮箱，也不是 3K。工业 RV **自己带一级行星**，赢在摆线主减速的刚度和抗冲，不是「里面没有齿轮」。总比公式见 [结构](./structure.md)。

摆线这边占优：

| | 摆线 / RV | 多级 NGW 行星 |
|---|---|---|
| 减速比 | 单级常见 30–200，一档到髋膝常用比 | 单级约 3–10；大比靠串级，轴向变长，回差累加 |
| 同时受力 | 多齿同时啮合，冲击摊在一圈针齿上 | 几颗行星轮分担，冲击先打在少数齿上 |
| 扭转刚度 / 抗冲击 | 高。落地、急停先看这档 | 中。笼式好于悬臂，仍低于同扭矩档工业 RV |
| 回差 | 多齿啮合加主轴承预紧，可以做小 | 看齿隙等级和级数，通常大于精密 RV |

行星这边占优：

| | 多级 NGW 行星 | 摆线 / RV |
|---|---|---|
| 效率 | 高。同功率高于摆线 | 低于同功率 NGW。口头常 70–85%，高速、大比更差，以样本为准，见 [额定](./ratings.md) |
| 可回驱 | 低比（约 6–10）准直驱还能回驱，电流估力矩更靠谱 | 大比加偏心曲柄，摩擦大，力透明度差 |
| 输入转速 | 渐开线高速档更熟 | 曲柄轴承吃偏心高速，输入转速上限更紧 |
| 重量 / 厚度 | 级数定了就定了，小扭矩轴更好塞 | 工业 RV 偏重偏厚。轻量化摆线减重之后，弯矩不能抄工业表 |
| 供应 | 渐开线、模数、精度等级现成，相对好买 | 针齿成套、摆线齿廓、曲柄轴承绑在厂家，重载档贵 |
| 中空 | 很多规格能让出中心孔 | 曲柄占中心，中空是单独规格，孔径和扭矩一起掉 |

怎么选：髋、踝冲击和弯矩大，又要单级大比和扭转刚度，用摆线，**重量和厚度先冻**。要转速、效率、成本，冲击不大，或者要低比回驱，留行星。腕、肘要薄要中空，两条都先让给谐波，分流见 [结构](./structure.md)。

坑：

- 只比峰值扭矩。行星样本峰值和 RV 瞬时最大都不是行走额定。
- 刚度和重量各取一半：工业 RV 的刚度配轻量化摆线的重量，规格上没有这台。
- 把 RV 当成纯摆线。前级就是渐开线行星，总比不是两级相乘。
- 用低比行星的回驱手感去要求一百档摆线。比差一个数量级，控制和发热不是同一件事。
- 摆线空程变大先查主轴承弯矩和针齿磨损。行星侧隙变大才是齿。

## 选型必须冻结

- [ ] 类型：工业 RV / 纯针摆 / 轻量化摆线；元件组还是带壳整机  
- [ ] 实心轴还是中空；中空孔径与走线  
- [ ] 减速比（常见 30–200 档，以样本为准）  
- [ ] **额定 / 启动停止 / 瞬时最大** 三个扭矩，不要混  
- [ ] 扭转刚度、回差或空程档  
- [ ] 许用弯矩、轴向 / 径向（髋侧向力常先打主轴承）  
- [ ] 重量、外径、厚度  
- [ ] 输入：太阳轮/齿轮轴与电机轴配合、许用输入转速  
- [ ] 润滑脂、注脂量、安装方向（立式/卧式脂分布不同）  
- [ ] 寿命口径对应哪条负载谱，不是工业均匀负载直接套人形  

## 配套

- **电机：** 输入转速和转子惯量要落在 RV 许用内；轻量化摆线常与无框集成为模组。见 [无框电机](../../frameless-motor/README.md)。  
- **编码：** 电机侧换向；关节侧看输出盘真实角（回差和主轴承游隙都在这边）。  
- **结构：** 针齿壳、输出盘安装面平面度；主轴承是否已集成，没有则连杆弯矩打到针齿。  

## 一句话坑

工业 RV 当人形髋「稳妥件」→ 重量厚度让整机走不起来；只比扭矩不比刚度和弯矩 → 落地后空程变大；样本寿命按工业均匀负载 → 人形启停谱完全不同。
