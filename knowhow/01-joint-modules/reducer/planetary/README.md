# 行星减速机

**大类：** [关节模组](../../README.md) · **小类：** [减速机](../README.md)

伺服关节里的行星减速机，默认是 **渐开线圆柱齿轮 + 周转轮系**。功率由多颗行星轮分流，同扭矩下比平行轴齿轮箱更短、更同轴。

往下几页必须分开读：

| 页 | 讲什么 |
|---|---|
| [结构类型](./types.md) | NGW / 星型 / NW / NN / NGWN / WW、多级与差动 |
| [齿轮与齿系](./gears.md) | 模数、齿形、变位、精度、定轴 vs 周转、配齿四条件 |
| [行星架](./carrier.md) | 笼式（双侧支撑）vs 悬臂式；倾覆刚度与装配 |

买货时厂家样本几乎都是 **多级 NGW**；审非标图或准直驱自研时才会碰到 NW、星型。字母对不上，减速比公式整页作废。行星架是笼是悬臂，比公式另算一刀，见 [carrier.md](./carrier.md)。

## 四个构件（NGW 默认）

| 构件 | 位置 | 关节减速机里通常干什么 |
|---|---|---|
| 太阳轮 | 中心，常与电机轴直联 | **输入** |
| 行星轮 | 太阳与齿圈之间，一般 3 颗 | 自转 + 公转，分流载荷 |
| 内齿圈 | 最外圈，多数与箱体固定 | **固定件** |
| 行星架 | 托行星轮轴，接输出法兰 | **输出**（笼式 / 悬臂见 [carrier.md](./carrier.md)） |

行星轮颗数 **不改变 NGW 减速比**，只改变均载、刚度和装配难度。

## 在机器人里干什么

效率高、转速能力强、成本相对可控：直线关节前级、腰、轮、部分髋；准直驱常用单级或 NW 把比做到 6–20。腕/肘要极薄中空、回差极小，谐波往往更合适。

## 选型必须冻结

- [ ] 结构类型：NGW / NW / 星型……以及几级（见 [types.md](./types.md)）
- [ ] 总减速比；齿圈固定、太阳入、行星架出是否成立
- [ ] 额定 / 峰值 / 急停扭矩；持续工作建议落在额定 50–70%
- [ ] 回差（arcmin）与扭转刚度，分开冻
- [ ] 惯量：`(J_负载 / i²)` 对电机转子，高精度轴常希望 ≤ 3
- [ ] 模数、齿制（直/斜）、精度等级（见 [gears.md](./gears.md)）
- [ ] 行星架：笼式 / 悬臂；许用弯矩（见 [carrier.md](./carrier.md)）
- [ ] 输出法兰/轴伸/空心；输入止口、轴径、轴长、键
- [ ] 润滑与安装方向

**回差：** 输出锁死，输入正反转到约额定扭矩 ±2%，输入端微小转角。问清折算到输入还是输出。

| 回差 | 大概用途 |
|---|---|
| < 3′ | 关节、精密转台 |
| 3′–10′ | 一般自动化 |
| > 10′ | 单向输送，不适合定位关节 |

## 验收与坑

- 同外形不同回差档是常见货，订单必须写档  
- 直齿改斜齿会改噪音和轴向力；斜齿若轴向限位不足会窜动拍打，样品与小批要同一齿制（见 [gears.md](./gears.md)）  
- 私改适配法兰，同轴差先打死行星轮轴承  
- 样品按笼式刚度调参，到货悬臂架，倾覆一软全线抖  
- 不要把行星轮齿数当减速比调（NGW 公式里没有它）  
- `T_电机 × i` 不是额定，要扣效率并校峰值和弯矩
