# 齿轮与齿系

**大类：** [关节模组](../../README.md) · **小类：** [减速机](../README.md) · **细分：** [行星减速机](./README.md)

行星减速机里转的是 **渐开线圆柱齿轮**。先分清齿系（谁的轴在动），再谈模数、齿形、变位、精度。结构类型见 [types.md](./types.md)。

---

## 1. 齿系：定轴、周转、复合

| 齿系 | 轴转不转 | 行星减速机里 |
|---|---|---|
| **定轴轮系** | 所有齿轮轴线相对机架固定 | 普通平行轴减速器；**星型 NGW**（架钉死）也是定轴 |
| **周转轮系** | 至少有一根轴线（行星轴）绕另一根转 | **行星减速机本体** |
| 　└ 行星轮系 | 周转轮系 + 钉死一个中心件，自由度 1 | 齿圈固定的 NGW / NW |
| 　└ 差动轮系 | 三个基本件都能转，自由度 2 | 混动分流，不是关节默认 |
| **复合轮系** | 定轴 + 周转拼在一起 | 多级 NGW、封闭差动 |

周转轮系算速比，用 **转化机构法**（给整个机构加一个 `−n_行星架`，当成定轴轮系算完再变回来）：

```text
(n_太阳 − n_架) / (n_齿圈 − n_架) = i_转化
```

NGW 转化机构里太阳→齿圈是「外啮合再内啮合」，`i_转化 = −Z_齿圈 / Z_太阳`。齿圈固定 `n_齿圈 = 0` 就回到：

```text
i = n_太阳 / n_架 = 1 + Z_齿圈 / Z_太阳
```

这就是为什么 **行星轮齿数不进 NGW 减速比**：转化机构里它是惰轮，对速比符号和大小的贡献被两对啮合消掉了。NW 的双联齿 **不是** 惰轮，两档齿数都进公式，见 [types.md](./types.md)。

## 2. 模数：齿轮的「尺子」

模数 `m` 的单位是 mm，表示一齿分到的分度圆直径：

```text
m = d / Z = p / π
d = m · Z          分度圆直径
p = π · m          齿距
a = m (Z1 + Z2) / 2     外啮合中心距（标准、未变位）
a = m (Z2 − Z1) / 2     内啮合中心距
```

![渐开线齿轮：分度圆、基圆、齿距、齿厚与压力角](./involute-geometry.png)

斜齿用 **法向模数 `mn`**（刀具模数）和 **端面模数 `mt = mn / cos β`**。中心距、齿数关系一律用端面。

国标优先模数（节选）：0.5, 0.6, 0.8, 1, 1.25, 1.5, 2, 2.5, 3……  
人形关节行星常见大约 **0.3–1.5**。模数大：齿厚、抗弯、抗冲击好，同样外径齿数少、减速比难做细、噪音和回差的「一齿」也更大。模数小：比好做、运转密，但断齿、磨粒、热处理变形更敏感。

同一台 NGW 里太阳、行星、齿圈 **通常同一模数**。NW 两档可以不同模数，但中心距必须同心（见下节变位/同心）。

下单不写模数也可以，但非标审图必须写：模数、齿数、变位系数、齿宽、精度等级。只写「i=10」不够。

## 3. 齿形参数（渐开线）

关节行星几乎全是 **渐开线**，压力角默认 **20°**（欧美有 14.5°/25°，对齿厚和重合度有影响，不要混用刀具）。

标准直齿（齿顶高系数 `ha* = 1`，顶隙系数 `c* = 0.25`）：

| 量 | 公式 |
|---|---|
| 齿顶高 | `ha = 1 · m` |
| 齿根高 | `hf = 1.25 · m` |
| 全齿高 | `h = 2.25 · m` |
| 齿顶圆 | 外齿轮 `da = d + 2m`；内齿轮 `da = d − 2m` |
| 齿根圆 | 外齿轮 `df = d − 2.5m` |

**重合度 `ε`：** 同时接触的齿对数。直齿常要 `ε > 1.2`；斜齿还有轴向重合度，更稳、更静，但产生 **轴向力**，轴承和箱体要能扛。

### 直齿 vs 斜齿 vs 人字齿

齿向相对轴线：直齿平行；斜齿有螺旋角 `β`（常见十几度）；人字齿两侧螺旋反向。

| | 直齿 | 斜齿 | 人字齿 |
|---|---|---|---|
| 啮合 | 齿宽几乎同时碰上 | 一端逐渐切入，重合度更高 | 更稳 |
| 噪音 / 振动 | 一般 | 好 | 更好 |
| 轴向力 | **无**（啮合不产生） | **有** | 理论上两侧抵消 |
| 成本 / 工艺 | 便宜、好做 | 更贵；要法向模数 + `β` | 更贵、更厚 |
| 关节行星 | 能用，成本档常见 | **精密档常见** | 轴向太厚，关节少见 |

不是「斜齿一定更好就换」。换齿制等于换力系：噪音变、轴承载荷变，样品与小批必须同一齿制。

### 斜齿的轴向力会怎样

斜齿齿面法向力可分成圆周力（传扭矩）、径向力、**轴向力**。轴向力顺着轴推/拉齿轮，螺旋角越大、扭矩越大，轴向力越大。

常见后果：

1. **轴承多扛轴向载荷** — 行星销上的滚针/球轴承、太阳轮与电机端轴承要从「主要径向」改成「径向 + 轴向」校核，不能抄直齿寿命曲线。  
2. **轴 / 行星架 / 箱体被顶歪** — 支承软或悬臂架时，孔系微偏 → 齿面偏载、噪音和磨损一起上。架类型见 [carrier.md](./carrier.md)。  
3. **端隙被推满、正反转拍打** — 关节频繁换向时，轴向力方向可能对调；游隙大就两头撞挡肩/轴承，异响或打坏挡圈。  
4. **效率与发热** — 不一定明显差，但轴承载荷更大时整机损耗和温升要留余量。  
5. **轴向限位必须设计清楚** — 轴肩、挡圈、能吃轴向力的轴承（或成对布置）要写进结构，不能按直齿「松一点」装。

### 斜齿会导致轴向窜动吗

**斜齿 ≠ 必然窜动。** 斜齿带来的是轴向力；窜动是 **有轴向力却没有可靠轴向限位** 时的结果。

| 情况 | 结果 |
|---|---|
| 斜齿 + 轴肩/挡圈/轴承轴向限位到位 | 正常：有轴向力，工作中轴向位置基本固定 |
| 斜齿 + 只当径向轴承用、端隙大 | 易窜动、拍打、异响、打坏挡圈或轴承 |
| 直齿 | 啮合不产生轴向力；若窜动，多半是装配松、轴承坏或冲击，不是齿制本身 |

怕的不是「有轴向力」，而是 **有轴向力却按直齿方式装**。人字齿轴向力理论上抵消，窜动风险小，但关节里少见。

### 直齿 / 斜齿怎么选（口头）

**斜齿优点：** 重合度高、更稳更静；同尺寸承载往往更好；小齿数时相对直齿更不易根切（常再配合变位）。  
**斜齿缺点：** 有轴向力；轴承与箱体更贵；加工对齿更严；螺旋角越大越静也越「推」——`β` 不是越大越好。  
**直齿优点：** 无啮合轴向力、结构简单、便宜。  
**直齿缺点：** 噪音与冲击一般更差，精密关节少当默认。

```text
精密关节、要低噪平稳
  → 斜齿；行星轴/电机轴轴承按轴向力校；轴向限位写清

成本紧、轴向力不想管
  → 直齿可以；接受噪音档

样品直齿、小批改斜齿（或反过来）
  → 否决；等于换机型
```

**最少齿数：** 20° 标准直齿、不变位，外齿轮大约 17 齿以下根切。太阳轮要小齿数冲减速比时，必须 **正变位** 或用斜齿/变齿厚，不能偷偷减齿。

## 4. 变位（x）干什么

变位系数 `x`：刀具相对毛坯多进或少进。正变位齿厚增加、齿顶变尖；负变位相反。

行星里变位主要不是为了「优化齿形好看」，而是：

1. **凑同心** —— 标准齿 `Z_齿圈 = Z_太阳 + 2 Z_行星` 对不上目标齿数时，用角度变位让两对中心距仍相等  
2. **抗根切** —— 太阳轮齿数偏少  
3. **配强度** —— 太阳轮正变位加厚，内齿圈略负变位  

审图看到 `x≠0` 是正常的。变位后 **不能再用** `d = mZ` 当工作节圆去算中心距，要用啮合角 `α'`：

```text
a' = m (Z1 ± Z2) / 2 · (cos α / cos α')
```

外啮合取 `+`，内啮合取 `−`。NGW 要求太阳–行星中心距 = 行星–齿圈中心距。

## 5. 配齿四条件（审非标必勾）

| 条件 | NGW 直齿、标准或高变位时 |
|---|---|
| **传动比** | `i = 1 + Z_B / Z_A` 对得上订单 |
| **同心** | `Z_B = Z_A + 2 Z_C`（变位则改用中心距相等） |
| **装配** | 多颗行星同时啮入：常用 `(Z_A + Z_B)` 能被行星颗数 `Cs` 整除 |
| **邻接** | 两颗行星齿顶不相撞，间隙 ≳ `0.5 m` |

`A` 太阳、`C` 行星、`B` 齿圈、`Cs` 行星颗数（3 或 4）。

NW 同心改成两档中心距相等，装配还要管双联齿的相位（两档齿槽对称线相对行星轴同侧还是两侧），不能按 NGW 那一套抄。

**均载：** 三颗行星理论上各扛 1/3，制造误差会偏载。高精度靠齿距精度 + 太阳轮浮动或柔性销；没有均载措施，样本扭矩要打折。

## 6. 精度、侧隙、模数怎么一起看

圆柱齿轮精度常见 **GB/T 10095 / ISO 1328**，级数越小越精。关节用精密行星，工作齿距/齿向大概落在 **5–7 级** 量级（以厂家样本为准）。

侧隙（齿槽比齿厚多出来的空）太大 → 回差大；太小 → 热胀咬死、润滑差。回差是 **整机输出/输入测出来的角**，不是单把模数写小就会变好。模数、中心距公差、轴承游隙、箱体变形一起贡献回差。

齿宽 `b`：太窄接触应力爆；太宽均载更差、对齿向误差敏感。样本里的额定扭矩已经按他们的齿宽和硬度算过，改齿宽等于改型号。

材料与热处理（只记采购要问的）：渗碳淬火齿轮常见，齿面硬、芯部韧；内齿圈有时氮化。硬度、有效硬化层、磨齿还是刮齿，决定寿命和回差能不能保持。

## 7. 和电机、谐波怎么咬

- 模数、齿数定了减速比和强度；**Kv/Kt 在电机页**，不要用模数去「估电机扭矩」。  
- 内转子 + 多级 NGW + 谐波 是两种不同减速，不要在同一级里混算 `i`。  
- 外转子准直驱往往 **单级 NGW 或 NW**，模数可以略大以抗冲击。见 [无框电机](../../frameless-motor/README.md)。
