# 行星结构类型（NGW / NW / …）

**大类：** [关节模组](../../README.md) · **小类：** [减速机](../README.md) · **细分：** [行星减速机](./README.md)

国产手册用字母标啮合方式，不是品牌型号：

| 字母 | 含义 |
|---|---|
| **N** | 内啮合（行星轮 ↔ 内齿圈） |
| **W** | 外啮合（行星轮 ↔ 太阳轮，或两外齿轮） |
| **G** | 公用行星轮：同一圈齿同时跟太阳轮和齿圈啮合 |

再叠一套库氏分类：**2K-H** = 两个中心轮 + 行星架（关节里绝大多数）；**3K** = 三个中心轮（NGWN）；**K-H-V** = 摆线那套，工业 RV 再封闭一级渐开线行星，见 [摆线 / RV](../cycloidal/README.md)。

## 对照（关节用不用）

| 类型 | 行星轮 | 单级比（常见/推荐） | 关节模组 |
|---|---|---|---|
| **NGW** | 单齿圈，同时内外啮合 | 约 2.7–9（极限约 1.1–14） | **默认**，再多级串联 |
| **NGW 星型** | 同上，但行星架固定 | 约 3–8，**反向** | 少见（高速定轴） |
| **NW** | **双联**行星（两档齿） | 约 7–21（极限可到 ~50） | 准直驱、想单级大比 |
| **NN** | 双联，两档都是内啮合 | 大比、结构怪 | 关节几乎不用 |
| **WW** | 双联，两档都是外啮合 | 约 1.2–20 | 变速箱/高速箱，关节少 |
| **NGWN（3K）** | 三中心轮：太阳 + 两内齿；双联行星 | 单级大比，效率掉 | 绞车/个别一体化大比；关节要慎用，见下节 |
| **多级 NGW** | 几排 NGW 串 | 16 / 20 / 25 / … / 100 | **样本上的 2 级、3 级** |
| **差动** | 太阳、齿圈、行星架都能转 | 两输入 | 混动，不是伺服减速机 |

问供应商「是不是 NGW、几级、齿圈是否固定」，比问商品名有用。

## 1. NGW（关节默认）

```text
        内齿圈（N，常固定在壳体）
     ●     ●     ●     ← 行星轮 G：一圈齿既外啮合又内啮合
        太阳轮（W，电机输入）
              ↓
           行星架输出
```

转化机构（假想把行星架钉住）里：太阳↔行星是外啮合，行星↔齿圈是内啮合。

**齿圈固定、太阳输入、行星架输出**（减速、同向）：

```text
i = n_太阳 / n_行星架 = 1 + Z_齿圈 / Z_太阳
```

行星轮齿数不进 `i`。标准变位、模数相同时同心条件简化为：

```text
Z_齿圈 = Z_太阳 + 2 × Z_行星
```

例：太阳 20、行星 40、齿圈 100 → `i = 1 + 100/20 = 6`。

效率高、好做、好配齿。单级比上不去：太阳太小会根切、太弱；行星太瘦邻接碰齿。所以样本里 10 以上基本是 **两级 NGW**，轴向变长、回差累加、效率略降。

同一套 NGW 换固定件：

| 固定 | 输入 → 输出 | i | 转向 | 用途 |
|---|---|---|---|---|
| 齿圈 | 太阳 → 行星架 | `1 + Zr/Zs` | 同向 | **关节减速** |
| 齿圈 | 行星架 → 太阳 | 上面的倒数 | 同向 | 增速，关节不用 |
| 行星架 | 太阳 → 齿圈 | `−Zr/Zs` | **反向** | 下面星型 |

---

## 2. NGW 星型（准行星）

构件还是 NGW，但 **行星架固定**，行星轮只自转、不公转，变成定轴轮系。太阳输入、齿圈输出，转向相反：

```text
i = − Z_齿圈 / Z_太阳
```

行星轮轴承不受公转离心力，适合高速。关节模组要的是同向减速、还要中空和扁，星型很少进人形关节。

---

## 3. NW（双联行星，单级大比）

行星轮是 **两档齿做在一根轴上**（双联）：

```text
太阳 A  --外啮合 W-->  行星大齿 C
                         ‖ 同一根行星轴
内齿圈 B --内啮合 N-->  行星小齿 D
行星架托着双联轴，齿圈常固定，太阳入、行星架出
```

转化机构速比带两对齿：

```text
i = 1 + (Z_齿圈 × Z_行星C) / (Z_太阳 × Z_行星D)
```

C 比 D 大，单级就能到十几、二十，轴向往往比「两级 NGW」短，但：

- 双联相位在加工时就定死，配齿和装配比 NGW 苛刻  
- 两档模数可以不同，同心条件改成中心距相等：`m_AC(Z_A+Z_C) = m_BD(Z_B−Z_D)`  
- 均载更难，精度和浮动结构要跟上  

准直驱、想单级 8–20 又不愿加第二排 NGW 时值得谈 NW。别和 NGW 用同一套 `1+Zr/Zs`。

双联轴更长，悬臂行星架几乎必然偏载；NW **默认按笼式（双侧支撑）谈**，见 [carrier.md](./carrier.md)。

---

## 4. NN / WW

**NN：** 两对都是内啮合，还是双联行星。能做大比，内齿圈加工贵、润滑和装配别扭，关节模组基本不碰。

**WW：** 两对都是外啮合，也常做成星型（架固定、两太阳轮一入一出）。汽车变速、高速箱常见，人形关节少见。

字母记法：看行星轮两端到底是 N 还是 W，不要靠商品名猜。

## 5. NGWN（3K）设计思路

库氏分类里 **3K** = 三个中心轮（都是「K」）。字母写法常叫 **NGWN**：前面是 NGW 那一套（太阳外啮合 + 一级内齿），后面再加一套内啮合（第二个内齿圈）。行星侧通常是 **双联齿**（一档跟太阳/一级齿圈，另一档跟输出齿圈）。

关节样本默认仍是多级 NGW。3K 出现在：自研一体化模组要 **单级很大比**、轴向不想串两排 NGW，又暂时不上谐波的场合。卷扬、个别机器人模组论文/专利里常见；当「现货精密行星」买时要先问清是不是 3K，公式和效率都不能抄 NGW。

### 5.1 构件怎么认

```text
        内齿圈 B（一级，常固定在壳体）     内齿圈 E（二级，常作输出）
              │                                    │
         N 内啮合                              N 内啮合
              │                                    │
           行星 C ════ 同一根双联轴 ════ 行星 D
              │
         W 外啮合
              │
           太阳 A（电机输入）
              │
           行星架 H（托双联轴；3K 里架通常不是输出）
```

口头对应（不同教材字母会换，下单写齿数和图，不写「那个大齿圈」）：

| 件 | 常见角色 |
|---|---|
| **A** | 太阳轮，**输入** |
| **B** | 一级内齿圈，**固定**（最常见） |
| **C / D** | 双联行星的两档齿 |
| **E** | 二级内齿圈，**输出** |
| **H** | 行星架，只托轴，一般不接法兰 |

和 2K-H（NGW）的差别：NGW 输出是 **行星架**；3K 输出常常是 **第二个内齿圈 E**，架在中间「空转托着」。别把 3K 的输出法兰当成笼式 NGW 的架。

### 5.2 速比（B 固定、A 入、E 出）

转化机构（钉住行星架）后，按两对啮合串起来。工程上常用（齿数符号与上表一致）：

```text
i_AE^B = n_A / n_E = (Z_A + Z_B) · Z_C · Z_E
                     / [ Z_A · (Z_C · Z_E − Z_B · Z_D) ]
```

分母里出现差值，是 3K 能「单级很大比」的来源：两档行星齿数、两内齿圈齿数接近时，差值小 → `i` 暴涨。也因此：

- 齿数差几个齿，比可以翻一倍——**配齿误差对速比极敏感**  
- 小差值处啮合滑动与效率损失通常更狠  
- 公式依赖「谁固定、谁输出」；B、E 对调或架输出时整页作废，必须按实际简图重推

设计时不要先拍一个 `i=100` 再硬凑齿数；先定外径与模数天花板，再在可加工齿数里扫能满足装配条件的组合。

### 5.3 设计思路（按这个顺序）

**1. 先问该不该上 3K**

```text
要 i 大、轴向极短、能接受效率/热/回差变差、有能力自研配齿
  → 可以评 3K

要现货、要效率、要小回差精密关节
  → 多级 NGW 或谐波；不要默认 3K

供应商说「大比行星」
  → 追问是两级 NGW、NW，还是 3K（NGWN）
```

**2. 分配「看起来像两级」的比**

手册常把 3K 看成 **高速 NGW 段 + 低速 NN 段** 合在一根双联行星上。先定总 `i`，再拆成两段合理区间（而不是一段 3、一段 40），避免某一档模数过小或齿差过疯。

**3. 配齿四件事一起满足**（比 NGW 多一截）

| 条件 | 3K 里特别要注意 |
|---|---|
| **同心** | A–C 与 B–C、以及 D–E 的中心距必须同心；模数可以两档不同，但中心距方程要联立，见 [gears.md](./gears.md) |
| **邻接** | 多颗双联行星外圆不能碰；齿宽、轴距比 NGW 更紧 |
| **装配** | 行星颗数 `n_p` 常取 3；`Z_A`、`Z_B`、`Z_E` 等常取 `n_p` 的倍数，否则转一圈对不进齿 |
| **强度** | 小齿差、大比时接触应力与胶合风险上升；输出齿圈 E 与双联弱档要单独校 |

经验口径（不是定理）：希望 `Z_B` 与 `Z_E` 不要离太离谱；许多手册在同向大扭矩时推荐 `Z_B > Z_E` 一类组合——以你用的手册/仿真为准，写进计算书。

**4. 效率与热放在和速比同等位置**

3K 啮合对数多，效率公式比 NGW 长一截（转化机构里还要叠两对损失）。一体化模组论文里会用变位、中心距去抬啮合效率——说明 **默认效率往往不好看**。冻结时要：

- 样本或自研的效率曲线（对扭矩、转速）  
- 温升与脂型号；封闭关节里 3K 比同体积 NGW 更容易先热  

靠电机电流估外力时，效率低 = 力感知更不透明，见驱动与整机控制口径。

**5. 结构与轴承**

- 双联行星轴更长 → **默认笼式/双侧支撑**，悬臂基本否决，见 [carrier.md](./carrier.md)  
- 输出若是齿圈 E：轴承布置、密封、中空走线与 NGW「架输出」完全不同，法兰接口要按齿圈输出画  
- 斜齿轴向力在多对啮合上叠加，更要轴向限位，见 [gears.md](./gears.md)

**6. 回差与控制**

侧隙、轴承游隙、箱体弹性叠在大 `i` 上，输出回差观感不一定「除以 i 就变好」。要大比又要关节级回差，先论证为什么不走谐波；走 3K 就要整机测回差档，不能只报齿侧隙。

### 5.4 3K 冻结清单（自研或审图）

- [ ] 简图：A/B/C/D/E/H 谁固定、谁输入、谁输出  
- [ ] 总减速比公式与齿数表；行星颗数  
- [ ] 两档模数、变位、同心条件计算书  
- [ ] 效率（或温升）目标；脂与散热路径  
- [ ] 行星架支撑：笼式；轴承寿命含轴向力  
- [ ] 输出件是齿圈还是架；法兰与密封按实际输出件  
- [ ] 整机回差档、扭转刚度；样品与小批同齿制  

### 5.5 坑

- 用 NGW 的 `1 + Zr/Zs` 去报 3K 的比。  
- 只追大比，齿差过小，效率与胶合一起爆。  
- 装配条件不满足，空载就别齿、异响。  
- 按 NGW 架输出开模具，到货是齿圈输出，编码与负载法兰全错。  
- 关节要小回差却选 3K 顶谐波，控制带宽和力感知都吃亏。

## 6. 多级 NGW（你买到的「i=20 / 50 / 100」）

```text
电机 → NGW 第1排 → NGW 第2排 → （第3排）→ 输出法兰
总 i = i1 × i2 × i3
```

样本整数比（3、4、5、7、10 再组合）是为了配伺服分辨率。每一排都有回差和弹性，**总回差不是单级除 i**，下单按整机回差档。

两级还是三级：比、轴向长度、效率、热一起看。别为了扭矩盲目加第三级把关节做成长筒。

---

## 7. 差动行星（不是减速机默认态）

太阳、齿圈、行星架三个都能转，两个输入合一个输出（混动功率分流）。自由度是 2。伺服关节减速机是把其中一个钉死，变成 1 自由度。采购口径不要按差动去谈。

---

## 关节上怎么选结构

```text
常规关节模组、跟谐波打配合、样本现货
  → 多级 NGW，齿圈固定

准直驱、单级就要 i≈8–20、轴向很紧
  → 谈 NW，或外转子电机 + 单级 NGW

高速试验台、行星架离心力受不了
  → 星型（架固定）

单级就要很大比、轴向极短、能扛效率与热
  → 可评 3K（NGWN）；配齿与输出件（齿圈 vs 架）单独冻

听说 NN / WW / 含糊的「大比行星」
  → 先问是两级 NGW、NW 还是 3K；关节默认仍优先 NGW / 谐波
```

配套电机是内转子还是外转子，见 [无框力矩电机](../../frameless-motor/README.md)。  
行星架笼式还是悬臂，见 [carrier.md](./carrier.md)。
