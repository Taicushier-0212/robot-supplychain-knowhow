# CNC 机加

**大类：** [结构件](./README.md)

## 1. 是什么

用铣、车、五轴等切出金属件。样机结构主路径。材料、表面处理、公差必须写在图纸和申购单里。

## 2. 在机器人里干什么

关节座、输出法兰、轴承室、高精度连杆接头。凡是配合面、同轴、销孔，优先 CNC。

## 3. 选型必须冻结

- [ ] 料号与图纸版本
- [ ] 材料牌号（如 6061-T651），禁止只写「铝」。见 [机加金属材料](./materials/README.md)
- [ ] 表面处理（阳极色号、膜厚、是否导电）。见 [表面处理](./surface/README.md)
- [ ] 关键尺寸与基准；配合件公差带。尺寸、形位和检法见 [公差与检测](./tolerances.md)
- [ ] 螺纹规格、是否要镶嵌件
- [ ] 必须打样的件 vs 可直接小批的件

## 4. 配套关系

阳极/热处理是外发二次，交期单列。处理后配合孔往往要再检或先留研磨量。

## 5. 验收要点

对照图纸关键尺寸与表面处理，不是「能装上」。承力件 Fail 不得口头让步。

## 6. 已知坑

- 公差全按「看起来精密」标，价格和交期一起爆炸；应圈关键尺寸。
- 阳极外发未写入交期，样品「7 天」变成 14 天。
- 薄壁件单件 FAI 过、装成组件后孔系偏。
- 3D 与 2D 不一致，厂按 3D 开、装配按 2D 检。
