# 注塑

**大类：** [结构件](./README.md)

## 1. 是什么

塑料开模件。外观、卡扣、绝缘罩常用。承力结构不要默认注塑。

## 2. 在机器人里干什么

外壳、指面、线卡、非承力装饰。样机用 3D 打印验证外形，确认后再开模。

## 晒纹

晒纹是做在表面上的凹凸纹理，英文常叫 texture。皮纹、梨皮、几何纹都算。它不是拉丝（一个方向的细丝），也不是 CD 纹 / 太阳纹（车出来的同心圆）。

外壳上的纹，默认做在模具里，注塑时印到零件上。金属件要直接做出纹，用蚀刻、喷砂或激光，和开模不是同一张单。

- [ ] 哪些面有纹。分型线、顶针、卡扣、配合面默认光面
- [ ] 纹板编号：VDI 3400 的等级，或 Mold-Tech 的 MT 号。只写「细皮纹」，两家厂不是同一张皮
- [ ] 纹越深，拔模角越大，否则顶出时沿出模方向把纹拉毛。角度按该纹板的表，不套光面件的拔模
- [ ] 喷漆会把细纹填平。先晒纹还是后喷、漆膜多厚，和纹深写在一起

验收拿纹板对指定面，不对照效果图。浇口附近发亮，是纹被冲浅。3D 打印件是光面，开模才加纹的话，卡扣和间隙要按带纹的状态再量一次。

## 3. 选型必须冻结

- [ ] 材料（PC / ABS / PA+纤 等）、收缩率
- [ ] 外观面、色号、是否喷漆；晒纹的纹板编号和有纹的面
- [ ] 嵌件、壁厚、卡扣寿命
- [ ] 年用量能否摊模具

## 4. 配套关系

与钣金/CNC 的卡扣和螺钉柱要对拔模。阻燃等级若进电器盒要写死。

## 5. 验收要点

外形、色差、卡扣力、嵌件拉拔。

## 6. 已知坑

- 打印件验证通过就开模，壁厚和圆角未按注塑重评。  
- 只写晒纹不写纹板号，或者光面拔模直接带深皮纹，顶出拉毛。
- 玻纤料磨损对配的铝件。
