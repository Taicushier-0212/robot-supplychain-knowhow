# 机加金属材料

**大类：** [结构件](../README.md) · **小类：** [CNC 机加](../cnc.md)

图纸上的材料必须是 **牌号 + 状态**。只写「铝」「钢」「航空铝」等于没冻。

| 页 | 讲什么 |
|---|---|
| [铝](./aluminum.md) | 6061、7075、6063、5052、2A12；压铸 ADC12 |
| [镁](./magnesium.md) | AZ31、AZ91、AM60、ZK60 |
| [钢](./steel.md) | 45、40Cr、42CrMo（钼）、P20 |
| [材料种类](./grades.md) | 碳钢、不锈钢、不锈铁、钛、铜的牌号归档 |
| [淬火与热处理](./heat-treatment.md) | 调质、渗碳/感应淬、介质、回火；和氮化怎么分 |

密度口头量级：镁约 **1.8**，铝约 **2.7**，钢约 **7.85** g/cm³。同样体积，钢大约是铝的 2.9 倍、铝大约是镁的 1.5 倍。减重先换材料族，不要在同一族里只改牌号指望重量掉一截。

## 选型必须冻结

- [ ] 牌号全称：6061-T651，不是「6061」；45 钢写正火还是调质  
- [ ] 产品形态：板 / 棒 / 型材 / 压铸件。ADC12 不是棒料  
- [ ] 关键件要质保书，核对牌号和状态  
- [ ] 表面处理跟牌号走。见 [表面处理](../surface/README.md)  
- [ ] 焊接会破坏 T6、调质，焊后状态单独写  

## 人形里怎么选

```text
关节座、法兰、要阳极外观
  → 6061-T6 / T651

同体积要更高强度，接受阳极发花、防腐差一档
  → 7075-T6 / T651；要抗应力腐蚀再谈 T73

压铸壳体
  → ADC12 一类，不要按 6061 棒料的强度和外观验收

再抠重量、厂能加工镁、防腐做微弧
  → 镁合金

销轴、工装、模具
  → 45 / 40Cr / 42CrMo / P20，不进轻量化连杆
```

## 坑

- 7075 当 6061 阳极，颜色发花还更易腐蚀。  
- 样机 CNC 用 6061，开模改 ADC12，强度和螺纹一起变。  
- 45 钢不写调质，来料有软有硬，销和孔配不上。
