# 铝合金

**大类：** [结构件](../README.md) · **小类：** [机加金属材料](./README.md)

机器人机加默认铝。牌号决定强度、阳极和能不能焊；**状态（T6、T651）决定这批料算不算那个强度**。下表是变形铝和压铸铝混在一张选型表里，采购不能互相替代。

强度是标准里常见的下限量级，板、棒、厚板不一样，以质保书和 GB/T、ASTM 为准。

## 变形铝（可 CNC 棒/板/型材）

| 牌号状态 | 是什么 | 强度口头 | 阳极 | 机器人里 |
|---|---|---|---|---|
| **6061-T6 / T651** | Mg-Si，最熟的结构铝 | 抗拉下限约 260–290 MPa 量级 | **最好做**，黑阳极匀 | **关节座、法兰、连杆默认** |
| **7075-T6 / T651** | Zn-Mg-Cu，高强度 | 抗拉下限约 500 MPa 量级，大约 6061-T6 的 1.7 倍 | 易发灰发花 | 应力够不到、又不能加厚时 |
| **7075-T73** | 同上，过时效 | 比 T6 低一档 | 同样不好看 | 要抗应力腐蚀的 7075 |
| **6063-T5 / T6** | 型材合金，强度低于 6061 | 明显低于 6061-T6 | 外观阳极很好 | [型材](../extrusion.md)、线槽，不当承力接头 |
| **6082-T6** | 欧系型材/板，接近 6061 | 略高于或接近 6061 | 可以 | 进口型材上常见，不要默认同 6061 互换 |
| **5052-H32** | 钣金防锈铝，不能热处理强化 | 低于 6061-T6 | 可以，亮度一般 | [钣金](../sheet-metal/README.md) 盒体，不是 CNC 棒料 |
| **2A12-T4**（旧称 LY12；美标家族接近 2024，不是同一张质保书） | Al-Cu-Mg | 高于 6061-T6，低于 7075。抗拉下限口头约 390–420 MPa 量级，随厚度变 | 差，易花 | 要强度、又还没到 7075；防腐和外观都不如 6061 |

密度都在约 2.7–2.8 g/cm³。7075 略重一点，减重靠少体积，不靠从 6061 换成 7075。

## T4 和 T6

T4、T6 是热处理状态，不是另一种铝。能写这两个状态的，是可热处理的牌号（6061、2A12、7075）。5052 用 H32 这种加工硬化状态，没有 T6。

两条路都先固溶、淬火，差别在之后的时效：

| | **T4** | **T6** |
|---|---|---|
| 怎么来的 | 淬火后放在室温里自然时效 | 淬火后再进炉人工时效 |
| 同一牌号里 | 更软，延伸更好，适合淬火后不久成形 | 强度更高，延伸更低 |
| 6061 | 软态，抗拉明显低于 T6。口头屈服只有一百多 MPa 这一档，以质保书为准 | **结构件默认**。只写 6061、不写 T6，厂可以交 T4 |
| 2A12 | **正常交货状态**。自然时效已经把它做硬，不是「还没时效所以偏软」 | 不按 6061 的炉温去「补成 T6」。那是另一个状态，防腐和强度都要重算 |

所以不能跨牌号比这两个字母。2A12-T4 比 6061-T6 更强；6061-T4 比 6061-T6 更软。牌号差别见下一节。

**T651** 是板材先拉伸消除应力，再做 T6。强度档次仍是 T6，精密铣不容易翘。关节座板料写 6061-T651，不要只写 6061，也不要把 T651 理解成比 T6 更硬。2A12 没有一个默认等于 T651 的写法，去应力要在订单上另写。

加工上，同一牌号的 T4 比 T6 黏刀，尺寸也更不容易守住。2A12-T4 因为本身已经硬，切削手感接近硬铝，不要按 6061-T4 的软料去留余量。刚淬火、自然时效还没完成的 2A12 很软，只能成形，不能当 T4 的成品强度使用；质保书写 T4，就是时效已经完成。

6061 可焊，焊缝热影响区 **T6 强度会掉**，焊后不重新热处理就不要按 T6 校核焊缝。7075、2A12 不按可焊结构用。

## 2A12 和 6061

2A12 是国标铝铜镁，旧图纸上的 LY12 就是它。6061 是铝镁硅。美标 2024 和 2A12 是同一族，成分接近，**质保书不能互相代替**：状态符号、包铝、厚度对应的强度下限都按各自标准走。

| | 6061-T6 / T651 | 2A12-T4 |
|---|---|---|
| 强度 | 结构铝里的默认档 | 明显更高，仍低于 7075-T6 |
| 防腐 | 裸件可用，外观阳极稳 | 铜高，裸件易腐蚀。薄板常带**包铝**，铣掉包铝层就失去这层保护 |
| 阳极 | 黑阳极匀，关节外观默认 | 发黄发花，不要和 6061 对同一块色板 |
| 焊接 | 能焊，焊缝不算 T6 | 不按焊接结构用 |
| 板料状态 | 精密铣写 **T651**（拉伸去应力） | 常见 **T4**（固溶后自然时效）。没有「默认等于 T651」 |

### 加工上差在哪

刀具、线速度是同一档硬质合金铝用参数。换牌号不是先去改一套转速，差在变形、表面和来料状态。

- **变形：** 6061 厚板写 T651，大面铣完不容易翘。2A12-T4 残余应力大，单面吃深、薄壁、不对称腔，加工完孔距和平面度会漂。工序要对称铣、多翻面，或者订单上单独写去应力 / 拉伸板。不写，厂按普通 T4 交，精加工之后再争论。
- **包铝：** 航空薄板的 2A12 常常两面包铝。安装面、配合面一铣，包铝不在了，防腐按裸 2A12 算，不能再按「板材样本不腐蚀」收货。棒料、厚板多数不包铝，图上要写是哪一种。
- **表面：** 6061 铣完可以直接阳极。2A12 铣削纹路能做到，阳极外观不稳定，关节外露面不要用它换黑色外观。
- **螺纹和薄壁：** 两种都能攻丝。2A12 更硬，丝锥寿命短一档，不是攻不出。同样载荷下 2A12 可以更薄，但薄壁更容易在铣的时候让刀、回弹，公差按 [公差与检测](../tolerances.md) 圈关键项，不要把 6061 的薄壁工艺原样套过去。
- **热：** 不要靠烘烤给 2A12 去应力。随便加温会把 T4 时效状态打乱，强度和尺寸一起变。

样机关节座、要黑阳极的法兰，仍用 6061-T651。强度不够先加厚或改局部结构，再到 7075；2A12 只在图样已经是这个牌号、或明确要它的强度又接受防腐和阳极时用。

冻结时 2A12 要写全：**2A12-T4**，板还是棒，包铝还是不包铝，成品检还是机加后检。只写「航空铝」或「硬铝」不算冻住。

## 压铸铝：ADC12

**ADC12**（JIS，硅大约 10–12%，含铜）是压铸牌号，不是棒料牌号。美标接近 **A380**，国标接近 **YL113**。见 [压铸](../die-cast.md)。

| | ADC12 | 6061-T6 棒/板 |
|---|---|---|
| 来料 | 压铸件，带气孔、拔模 | 轧制或挤压，致密 |
| 强度 | 样本抗拉常报 200–300 MPa 量级，**许用要扣气孔** | 按变形铝标准 |
| 延伸 | 低，螺纹和薄壁脆 | 明显更好 |
| 阳极 | 装饰黑易发花 | 适合黑阳极 |
| CNC | 只后加工安装面 | 整件铣 |

样机用 6061 铣出的外壳，开模改 ADC12 之前要重算壁厚、螺纹旋合和外观工艺（喷粉，不是阳极）。

## 和表面处理

- 6061 外观：普通阳极。见 [阳极](../surface/anodize.md)。  
- 7075：能阳极，不要和 6061 对同一块色板。  
- ADC12：外观走 [喷涂](../surface/coating.md)；要陶瓷膜再谈 [微弧](../surface/mao.md)。  
- 接地铝壳：导电氧化，不要整件绝缘阳极。  

## 来料公差：线材、棒材、板带

这是铝厂交货的尺寸偏差，不是零件图上的 H7，也不是车间口头的「一丝」。一丝、一条是 0.01 mm，见 [公差与检测](../tolerances.md)。名义直径合格，只说明落在材料标准那一档里，不能拿去当轴承档或销轴。

| 产品 | 标准里叫什么 | 现行尺寸标准 | 合同不写等级时 |
|---|---|---|---|
| **线材** | 拉（轧）制圆线材，直径一般到 10 mm | GB/T 3195-2023 | 看用途。铆钉线卷状按表 4 的 **C 级**；导体、焊接、镀膜的卷状按表 5 的 **D 级**；盘装焊丝按表 5 的 **A 级** |
| **棒材** | 挤压圆棒、方棒、六角棒。口头有时叫条 | GB/T 3191-2019 | 截面按 **D 级**。2010 版不写则按 **A 级**，两版差一档以上，年号要写上 |
| **板、带** | 轧制板材、带材 | GB/T 3880.3-2024 | **普通级**。冷轧和热轧、宽度不同，不是同一列 |

扁条、导电铝排不是上面的方棒。不要套圆棒的直径偏差。

### 线材（GB/T 3195-2023）

铆钉用线、成卷、不写等级，就是表 4 的 C 级，只许零或负：

| 直径 | C 级（默认） |
|---|---|
| ≤1.60 | 0 / −0.03 |
| >1.60～4.00 | 0 / −0.05 |
| >4.00～6.00 | 0 / −0.08 |
| >6.00～10.00 | 0 / −0.12 |

要更紧就写 A 级或 B 级。A 级在细线上是大约 ±0.015～±0.025 mm，不是 C 级再口头收一收。

导体、焊丝、镀膜线的卷状默认是表 5 的 D 级，对称偏差，比铆钉 C 级松。6～10 mm 这一档 D 级是 **±0.07 mm**。更细的直径以表 5 为准，合同要写用途，用途决定落在哪一级。直径用精度不低于 0.01 mm 的量具，不卡在卷的外圈椭圆处只量一次。

### 棒材（GB/T 3191-2019）

圆棒、方棒、六角棒同一张截面表。方棒、六角棒量的是对边，不是外接圆。

A～D 级只许负偏差，A 最紧，D 最松。E 级才是对称 ±。合同里的「高精级」管倒角、弯曲、扭拧，**不会**把直径从 D 级改成 A 级。直径等级要单独写。

不写等级按 D 级。以直径 >10～18 mm 为例：A 级是 0/−0.43 mm，D 级是 0/−1.30 mm。Φ12 的棒可以交到约 10.7 mm，加工余量不能按线材那种 0.05 mm 留。要车成 12 mm 的轴，棒要加大一档，或合同改写 A 级 / E 级。

定尺长度允许 **+15 / 0 mm**。倍尺每个锯口另加 5 mm。直径不大于 10 mm 的棒，允许用手轻压就能消除的弯曲，不按拉直的轴去退货。

### 板和带（GB/T 3880.3-2024）

不写就是普通级，而且还分冷轧、热轧和宽度。冷轧、宽度 ≤1000 mm、厚度 >1.50～1.80 mm，普通级是 **±0.06 mm**。热轧厚板到几十毫米，普通级偏差到 **±1 mm** 这一档。关节座厚板不要按冷轧带的公差收。

厚度在距侧边至少 10 mm、距端头至少 115 mm 处量，用 0.01 mm 千分尺。测得值不修约。

## 冻结与验收

- [ ] 6061-T6 还是 T651；7075-T6 还是 T73  
- [ ] 形态：线材 / 圆棒 / 方棒 / 六角棒 / 板 / 带；标准年号和偏差等级。不写时线材按用途默认级，棒按 3191-2019 的 D 级，板带按 3880.3-2024 普通级  
- [ ] 板厚/棒径够加工余量，不是成品名义尺寸。余量按上面那一档负偏差留，不按零件公差留  
- [ ] 质保书牌号、状态与图纸一致  
- [ ] 阳极件不用压铸料顶  

Fail：来料印字是 6063 或杂铝；7075 无状态；ADC12 按 6061 交尺寸和外观。

## 坑

- 「航空铝」到货是 6061，强度按 2A12 或 7075 设计。  
- 2A12-T4 按 6061-T651 的变形和黑阳极验收，铣完又翘又花。  
- 包铝薄板铣掉表面，仍按包铝的防腐签字。  
- 厚板不写 T651，精加工完孔距漂。  
- 6061 不写 T6，来料是 T4，按 T6 去校核关节。  
- 把 2A12-T4 理解成「欠时效的软料」，或拿去按 6061 的人工时效炉温烘成 T6。  
- 6061 焊缝按母材 T6 签字。
