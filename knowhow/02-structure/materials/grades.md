# 材料种类

**大类：** [结构件](../README.md) · **小类：** [机加金属材料](./README.md)

询价表上的大类只用来归档。下单写的是**某一个牌号 + 状态 + 形态**（板、棒、冷镦线）。同一格里的牌号不能互相替代。铝的状态和加工见 [铝](./aluminum.md)，国标结构钢见 [钢](./steel.md)，螺丝等级见 [紧固件](../../07-standard-parts/fasteners.md)。

表里的英文是来表用词。Commodity 是大类，Material Type 是牌号，不是热处理状态。

| 大类 | 来表牌号 | 下单时分开 |
|---|---|---|
| **碳钢** Carbon Steel | S40C；SRWCH6A、8A、10A、18A、22A；10B21 | S40C 是中碳棒料。SRWCH 是日标**冷镦钢丝**，数字大约对碳含量，用来打螺丝，不是板材。10B21 是含硼冷镦钢，强度靠后道热处理，不是来料就有 10.9 级 |
| **不锈钢** Stainless Steel | SUS302、303、304、316、316L、630、904L | 304 / 316 是奥氏体，不导磁、不能靠淬火变硬。303 加硫易切，耐蚀差一档。316L 低碳。630 是沉淀硬化（17-4PH 一类）。904L 是高合金，不要按 304 的价格和强度收 |
| **合金钢** Alloy Steel | SCM435；来表另写 SCM4037 | SCM435 是日标铬钼钢，接近 [42CrMo](./steel.md)。**SCM4037 先待核**：公开牌号里常见的是 SCM435、SCM440，不要自行改写成其中一个 |
| **特殊合金钢** | NiCo 2918；Co-Cr 合金 | 没有质保书上的原厂牌号之前，不用 SCM435 或 304 去顶。钴铬是耐磨、医用那一类，不是结构钢的加强版 |
| **不锈铁** Stainless Iron | SUS410、416、420、430、446 | 采购口头。冶金上仍是不锈钢里的马氏体或铁素体，**多数能被磁铁吸住**。410 / 420 可以淬火变硬；430 不能。耐蚀低于 304，户外和电解液里不要当 304 用 |
| **钛合金** | 来表写 TiA16VH、TC4、TC10 | **TiA16VH 按 Ti-6Al-4V 核对，就是 TC4**，不要拆成两个牌号。TC10 是另一种钛合金，不与 TC4 互换 |
| **铝合金** | 5052、5056、5154、6061、6063；来表写 AI7075、Al7A03、AlMg3 | 来表 AI7075 即 **Al7075**。6061 / 7075 的状态见 [铝](./aluminum.md)。5052、5154、AlMg3 是镁系，不能热处理成 T6。5056、7A03 常见于铆钉线，不是关节座棒料 |
| **黄铜** | H62、H65、C3604 | H62 / H65 是国标铜锌。C3604 是日标易切黄铜，含铅，切削好，和 H62 不是同一根棒 |
| **紫铜** | T1、T2 | 国标韧铜，含氧。导电排、母线常用 T2 |
| **无氧铜** OFHC | 来表写 C1100、C1020、Cu10100 | **C1020、C10100 才是无氧铜。C1100 是韧铜，接近 T2**，不要按无氧铜下单 |

## 和机器人零件怎么对

| 要做什么 | 从哪一格拿 | 不要 |
|---|---|---|
| 关节座、要阳极的法兰 | 6061，强度不够再 7075 | 5052 或黄铜去铣承力座 |
| 冷镦螺丝、铆钉的线材 | SRWCH、10B21、SUS302/304、7A03、5056 | 把线材牌号写成板材，或来料不热处理就当 10.9 级 |
| 销轴、要调质的轴 | 45、40Cr、42CrMo，或 SCM435 | 用 304 代替调质钢指望「不生锈所以更强」 |
| 要硬又要不锈的小轴 | SUS420 / 410 一类，写淬火硬度 | 叫不锈铁却按 316 的耐蚀验收 |
| 导电 | T2；要无氧再写 C1020 或 C10100 | C1100 和 T2 混成无氧铜 |
| 轻、耐蚀、又贵 | TC4 | 把 TiA16VH 和 TC4 买成两批料 |

螺丝和铝壳体挨在一起时，不锈钢和铝合金有电位腐蚀，见 [紧固件](../../07-standard-parts/fasteners.md)。碳钢螺丝要写表面处理，光杆碳钢在关节里会锈。

## 冻结

- [ ] 大类只用于归档；PO 上是一个牌号
- [ ] 形态：板、棒、冷镦线、铆钉线。SRWCH 和 10B21 默认是线，不是厚板
- [ ] 状态或热处理：调质、固溶、T6、沉淀硬化。10B21 和 SCM435 没有状态就没有强度
- [ ] 不锈铁要写具体 SUS，并写要不要导磁、要不要淬火
- [ ] 铜写清韧铜还是无氧铜
- [ ] 质保书牌号与 PO 一致。来表里的拼写错误不进 PO

## 已知坑

- 一格里从 SUS304 换成 SUS410，叫「还是不锈钢」，磁性和耐蚀都变了。
- SRWCH10A 和 10B21 按碳含量接近就互换。硼钢的淬透是另一回事。
- SCM4037 在群里被改成 SCM440 发出去，货对不上质保书。
- TiA16VH、TC4 各下一行，其实是同一种 Ti-6Al-4V。
- C1100 按无氧铜验收，含氧量不合格却已经当母线用了。
- C3604 铅黄铜用在要焊接或要食品接触的地方，H62 的焊接口径套不上。
