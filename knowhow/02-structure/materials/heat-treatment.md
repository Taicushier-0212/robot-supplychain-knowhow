# 淬火与热处理（钢）

**大类：** [结构件](../README.md) · **小类：** [机加金属材料](./README.md)

口头「淬一下」不够下单。淬火是 **加热到奥氏体区 → 快速冷却得到马氏体（或贝氏体）**；几乎总要再 **回火**，否则又脆又容易裂。牌号页见 [钢](./steel.md)；齿轮齿面硬化见 [行星齿轮 · 硬度](../../01-joint-modules/reducer/planetary/gears.md#7-齿轮硬度与热处理)。

铝的「淬火」是固溶后快冷，目的不同（锁住过饱和固溶体，再时效成 T4/T6），见 [铝](./aluminum.md)。下面默认讲 **钢**。

## 一张图分清

```text
退火 / 正火          → 软化、匀组织，方便机加或为淬火做准备
整体淬火 + 回火
  ├─ 低温回火        → 硬而耐磨（刃具、量具一类；结构销少用到极硬）
  └─ 高温回火 = 调质 → 强度 + 韧性平衡（轴、销默认常说的「调质」）
表面 / 局部淬火      → 感应、火焰、激光：只硬一层或一段
化学热处理后再淬
  ├─ 渗碳（+淬火回火）→ 低碳钢表面渗碳，面硬芯韧
  └─ 氮化 / 碳氮共渗 → 层更薄；氮化常常不靠「淬成马氏体」这条路
等温 / 分级淬火      → 控冷减少变形开裂（贝氏体、分级盐浴等）
```

「表面硬化」不要当料号：必须写清是渗碳、氮化还是感应淬。

## 淬火介质（冷却多快）

冷却越猛，越容易淬硬，也越容易变形、开裂。介质要和钢种、截面、变形要求匹配，图纸可写「油淬 / 水淬 / 气淬」，不要只写「淬火」。

| 介质 | 冷速口头 | 特点 | 机器人里 |
|---|---|---|---|
| **水 / 盐水** | 很快 | 便宜、硬得透；变形开裂风险大 | 简单件、淬透性差的碳钢有时用；精密轴少默认 |
| **油** | 中等 | 变形小一档，最常见结构件淬火 | **45 / 40Cr / 42CrMo 调质常见路径** |
| **聚合物水溶液** | 可调 | 介于水油之间，污染和控温要管 | 外协厂能力参差，要写进工艺 |
| **盐浴分级 / 等温** | 先等温再冷 | 变形小、可拿贝氏体 | 精密齿轮、复杂截面有时用；交期和价格另一档 |
| **气淬（真空炉）** | 看气压与气体 | 干净、变形可控；淬透能力看钢种 | 工模具、高合金；碳钢大气淬不一定够硬 |
| **空冷** | 很慢 | 只对空硬钢有意义 | 别把普通 45 钢「空冷」当淬火 |

同一牌号，水淬和油淬硬度可以差一截，变形差更多。换介质等于工艺变更，要重评尺寸。

## 常见「淬火」说法对照

| 口头说法 | 实际是什么 | 硬度口头 | 冻什么 |
|---|---|---|---|
| **整体淬火** | 整件加热淬透（或淬到心部一定深度） | 看回火温度 | 淬火介质、回火温度/硬度范围 |
| **调质** | 淬火 + **高温回火** | 常见约 HRC 20–35 或 HB 200–350 档（以图为准） | 硬度带；粗加工→热→精加工顺序 |
| **低温回火淬火件** | 淬硬后低温回火，保留高硬 | 可到 HRC 50+ | 脆、怕冲击；销轴慎用 |
| **渗碳淬火** | 低碳钢表面渗碳 → 淬火回火 | 面常 HRC 58–62；芯更韧 | **有效硬化层深度**、磨量 |
| **碳氮共渗** | 同时渗 C、N，层偏薄，温度可较低 | 面硬，层深通常浅于渗碳 | 层深；和渗碳不要混写 |
| **感应淬火**（含高频） | 线圈感应加热表面 → 喷冷 | 淬硬层可控 | 淬硬带位置、层深、软硬交界 |
| **火焰淬火** | 火焰扫过再冷 | 看操作 | 一致性差，精密关节少用 |
| **激光淬火** | 激光扫表面，自冷或辅冷 | 层浅、变形小 | 设备与轨迹要冻；量产要有产能 |
| **真空淬火** | 真空加热 + 气/油淬 | 看钢种与压力 | 光亮、少氧化；不是「一定更硬」 |
| **等温淬火（奥氏体等温等）** | 淬入热浴保温拿贝氏体等 | 韧硬兼顾、变形小 | 工艺窗口窄，要厂能力 |
| **氮化 / 离子氮化 / QPQ** | 渗氮形成硬层，**多数不是淬马氏体那条路** | 层薄、变形小 | 层深；磨穿即失效。QPQ ≠ 发黑，见 [发黑](../surface/black-oxide.md) |

渗碳、氮化是 **化学热处理**；感应、火焰是 **表面淬火**。采购单上写「表面处理：淬火」会收到任意一种。

## 回火为什么几乎必做

淬火马氏体硬、内应力大。不回火：易裂、易崩刃、尺寸不稳。

| 回火大致档 | 目的 | 典型 |
|---|---|---|
| 低温（约 150–250 °C） | 降应力、保高硬 | 刃具、量具、渗碳件常配 |
| 中温 | 弹性 | 弹簧一类 |
| 高温（约 500–650 °C） | 韧性和强度折中 = **调质** | 轴、销、结构件 |

焊后、再发黑、再喷粉：炉温可能把回火效果吃掉，状态要重写。见 [喷涂](../surface/coating.md)。

## 淬透性（别和「淬硬了」混）

- **淬硬**：表面或某处达到目标硬度。  
- **淬透**：心部也得到足够马氏体/规定组织。  

截面越大、钢淬透性越差，心部越软。45 钢大截面调质，边上硬心里软是常态；要心部也够，选 40Cr / 42CrMo 或改设计截面。图纸只写「淬火 HRC xx」、不写截面与测点，大件会验收扯皮。

## 工艺顺序（结构件）

```text
下料 → 粗加工（留余量）→ 热处理（淬+回 / 渗碳等）→ 精加工 / 磨
```

热处理会变形。配合孔、螺纹底孔、齿轮齿面：热前留多少、热后磨多少写进工艺卡。已经磨完再整体淬火，尺寸基本报废。

齿轮：渗碳件常磨齿吃层深；氮化件重磨可能磨穿——见 [齿轮硬度](../../01-joint-modules/reducer/planetary/gears.md#7-齿轮硬度与热处理)。

## 和表面处理的边界

| | 改硬度？ | 改尺寸？ |
|---|---|---|
| 淬火 / 调质 / 渗碳 / 感应 | 是 | 变形为主；渗层/氧化皮另说 |
| 发黑 | 否 | 可忽略 |
| 镀锌 / 镀镍 | 否（膜本身） | 有镀层厚 |
| QPQ / 氮化 | 表面是 | 有层厚，精密轴要留量 |

先热后镀。高强淬火件电镀注意氢脆与除氢。

## 冻结（下单 / 审图）

- [ ] 工艺名称：调质 / 渗碳淬火 / 感应淬 / 氮化…（不要只写「淬火」）  
- [ ] 淬火介质或炉型（油 / 水 / 气 / 盐浴），若影响变形  
- [ ] 回火要求或最终硬度范围（HRC / HB，测点）  
- [ ] 渗碳 / 感应：有效硬化层深度；心部硬度有没有要求  
- [ ] 热前 / 热后加工与余量；外发厂与交期单列  
- [ ] 质保：硬度报告；关键件金相或层深  

Fail：只写「淬火」；调质件按渗碳 HRC 58 验收；氮化当渗碳层深；热后不再检配合尺寸。

## 已知坑

- 45 钢不写调质还是正火，来料软硬乱跳。  
- 水淬图、油淬做，或反过来，变形开裂扯皮。  
- 淬完不回火就机加或装配，后期开裂当设计强度不够。  
- 大截面写死统一 HRC，心部根本淬不透。  
- 精孔磨完再整体淬，椭圆报废。  
- 「表面硬化」混用渗碳和氮化，磨齿策略全错。  
- 供应商换淬火油或换炉当作没变更，尺寸批次性飘。
