## 先看基材

| 工艺 | 主要基材 | 膜厚口头量级 | 尺寸 | 导电 | 机器人里 |
|---|---|---|---|---|---|
| 普通阳极 | 铝（6061 最好看） | 约 5–15 μm | 孔缩小、轴变大 | **绝缘** | 关节座、法兰外观 |
| 硬质阳极 | 铝 | 约 25–50 μm | 变化更明显 | 绝缘、更硬 | 滑动面、销孔耐磨 |
| 导电氧化 | 铝 | 约 1 μm 级 | 几乎不变 | **导电** | 屏蔽盒接地、喷漆前打底 |
| 发黑 | 钢、铸铁 | < 1 μm | 可忽略 | 看油膜 | 钢支架外观、轻防锈 |
| 磷化 | 钢 | 数 μm | 很小 | 不靠它导电 | 喷漆打底、防锈 |
| 喷粉 | 金属 | 约 60–120 μm | **明显** | 绝缘 | 外壳、防护罩 |
| 喷漆 | 金属、部分塑料 | 约 20–50 μm | 中等 | 绝缘 | 外观件、补色 |
| 电泳 | 金属 | 约 15–25 μm | 较小、内腔也有 | 绝缘 | 复杂盒体 |
| 微弧氧化 | 铝、镁、钛 | 约 10–60 μm | 明显，更粗糙 | **绝缘** | 镁骨架、耐磨陶瓷膜；不是装饰黑 |

压铸铝（ADC12 一类，硅高）做装饰黑阳极容易发花。要外观优先喷粉/喷漆，不要默认「和 6061 一样阳极」。

电镀（镀锌、镀镍）、不锈钢钝化、QPQ 会在询价里出现。紧固件镀层见 [紧固件](../../07-standard-parts/fasteners.md)。QPQ 是氮化，不是发黑，见 [发黑](./black-oxide.md)。

## 选型必须冻结

- [ ] 工艺名称写全：普通阳极 / 硬质阳极 / 导电氧化 / 碱性发黑 / 喷粉 / 喷漆 / 电泳 / 微弧氧化  
- [ ] 色号（RAL 或色板），不要只写「黑色」；微弧氧化按试样，不按阳极色板  
- [ ] 膜厚范围，以及是单面还是直径方向  
- [ ] 哪些面导电、哪些面绝缘、接地凸台  
- [ ] 保护：螺纹、轴承室、配合孔、密封面、定位销孔  
- [ ] 处理前还是处理后检关键尺寸；配合孔留不留量  
- [ ] 已装镶嵌件、磁钢、胶、密封圈的零件 **不能进炉、不能进槽**  

## 配套

- **机加：** 阳极和喷粉都会改配合尺寸。基准和关键孔在图纸上写「处理前/后」。见 [CNC](../cnc.md)。  
- **钣金：** 喷粉把接地面绝缘是常见事故。见 [钣金](../sheet-metal/README.md)。  
- **压铸：** 气孔遇高温喷粉会鼓泡。见 [压铸](../die-cast.md)。  
- **电气：** 屏蔽、接地、天线地要导电氧化或局部保护，不要整件绝缘阳极。  

## 一句话坑

交期只算机加；阳极后孔小装不上；螺纹喷死；该接地的面被喷粉盖住。塑料外壳上的皮纹、梨皮是晒纹，做在模具里，见 [注塑](../injection.md)。
