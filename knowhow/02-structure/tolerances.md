# 公差与检测

**大类：** [结构件](./README.md)

图纸上的公差分三层，检测手段不一样。口头说的「形位公差」，现行标准里叫**几何公差**（GB/T 1182，对应 ISO 1101）。下面仍用形位公差这个说法。

机加件的材料和图样版本见 [CNC](./cnc.md)。钣金的折弯累积不要套这页的平面度和孔距，见 [折弯](./sheet-metal/bend.md)。

| 层 | 管什么 | 图上长什么样 |
|---|---|---|
| **尺寸公差** | 长短、孔径、角度 | `30 ±0.05`，或 `⌀20 H7` |
| **形位公差** | 形状、方向、位置、跳动 | 方框：符号、数值、基准 |
| **表面粗糙度** | 加工纹路有多细 | `Ra 1.6` 这一类，不是形位公差 |

没标的尺寸不是「随便」。图框里要写未注公差按哪一档（常见 ISO 2768-m，或 GB/T 1804 的中等等级）。图框空着，供应商和 IQC 就没有共同标准。

## 一丝、一条

车间里的**一丝、一条、一道是同一个长度：0.01 mm**，也就是 10 μm。差两丝就是差 0.02 mm。南方多说丝、条，北方多说道。这是口语，图上仍写毫米。

| 口头 | 等于 |
|---|---|
| 一丝 / 一条 / 一道 | 0.01 mm |
| 两丝 | 0.02 mm |
| 五丝 | 0.05 mm |
| 十丝 | 0.10 mm |

**十丝 = 0.1 mm = 100 μm。** 1 mm = 100 丝。十丝刚好等于旧单位里的 1 丝米；一丝不是丝米，十丝才是。它不是线材，也不是棒材。铝厂交来的线、棒、板另有国标偏差，见 [铝合金](./materials/aluminum.md) 里的来料公差。

两个容易听错的「丝」：

- **丝米**是旧的米制名称，1 丝米 = 0.1 mm。车间说的一丝是忽米这一档（0.01 mm），不是丝米。听成 0.1 mm，公差放大十倍。
- 市制里的丝更小，大约 0.003 mm。机加图纸不用这套。

口头「公差一丝」只说明大小是 0.01 mm，没说是 `±0.01`、总带宽 0.01（也就是 `±0.005`），还是 `0 / −0.01`。写进图纸和检验记录时写成毫米，不写「一丝」或「一条」。

卡尺分度常见 0.02 mm，比一丝还粗，不能用来把一丝判成 Pass。百分表一格常见 0.01 mm，刚好是一丝，边界上仍不稳。这一档用分度 0.001 mm 的千分尺。

## 尺寸公差

两个数之间的允许范围。孔和轴写成配合代号时，范围在公差表里，不在图上展开成 ±。

| 写法 | 含义 | 检测 |
|---|---|---|
| `±0.1` | 双向对称 | 千分尺、内径量表。卡尺分辨率常见 0.02 mm，不能用来把 ±0.01 判成 Pass |
| `+0.02 / 0` | 只许大不许小，或反过来 | 同上，看上下极限，不看「差不多居中」 |
| `H7`、`g6` | 基孔制配合。H 是基准孔，字母在 h 之前是间隙 | 针规、塞规、内径千分尺。不把 H7 在嘴里换成一个 ± |
| 角度 `±0.5°` | 两条边的夹角 | 角度规或三坐标。折弯角不要套机加的角度，见钣金 |

轴承安装孔口头常写 **H7**，轴常写 **g6** 或 **h6**。以该轴承样本的配合表为准，不要全厂共用一个代号。

螺纹不量牙尖。用通止规：通端旋进，止端旋不进。卡尺夹在牙上的读数不能当中径。

## 形位公差

形状公差没有基准，零件自己和理想形状比。方向、位置、跳动必须有基准。基准是装配时真正靠上去的面或孔，按 A、B、C 标。基准选在毛坯边或去毛刺的棱上，三坐标建出来的坐标系和装配不是同一套，数没有用。

| 符号要控的 | 在关节里管什么 | 怎么测 |
|---|---|---|
| **直线度** | 导轨安装边、细长销 | 平台上打表，或三坐标。短边用刀口尺只能看缝，给不出图纸上的数 |
| **平面度** | 输出法兰、电机安装面 | 三坐标采点。平板加塞尺只能发现明显翘曲，法兰这一档不够 |
| **圆度** | 轴承室截面圆不圆 | 圆度仪，或三坐标。打表转一圈混进了偏心，不是圆度 |
| **圆柱度** | 轴承室、定位止口整段又圆又直 | 三坐标或圆度仪多截面。单有圆度、没有圆柱度，孔可以是锥的 |
| **平行度** | 两个安装面、连杆两侧 | 三坐标，相对基准面。卡尺量两端厚度只能看壁厚差 |
| **垂直度** | 法兰端面相对轴承孔轴线 | 三坐标，或孔里插芯轴后打端面。基准必须是孔的轴线，不是外圆 |
| **倾斜度** | 斜安装面相对基准成一个角 | 三坐标。角度规没有基准，检的是角度尺寸，不是倾斜度 |
| **位置度** | 销孔、螺纹孔、轴承孔相对基准在哪 | 无 Ⓜ：三坐标按基准算。有 Ⓜ：可以用综合量规，孔做到最小实体时位置允许放宽 |
| **同轴度** | 两端轴承孔、止口和外圆 | 三坐标。把零件转起来打外圆，得到的是跳动，里头还夹着圆度 |
| **对称度** | 槽、键槽相对中心平面 | 三坐标。卡尺量两边剩料只是粗看 |
| **圆跳动** | 转起来某一截面跳多少 | 芯轴或已装轴承当基准，千分表打一圈。基准错了，跳动量没有意义 |
| **全跳动** | 整段圆柱或整张端面转起来的包络 | 同样打表，表要沿轴向或径向扫过整段，不是只打一个圈 |
| **轮廓度** | 曲面、异形安装面 | 三坐标或扫描仪对 CAD。卡尺检不了 |

位置度方框里的 **Ⓜ（最大实体要求）** 决定检法。没有 Ⓜ，孔必须落在理论位置的圆柱公差带里，用三坐标。写了 Ⓜ，孔越小，位置可以偏得越多，现场可以用按最大实体尺寸做的综合量规：规过就是 Pass，规不过就是 Fail。两种算法不要混在一张报告里。

轮廓度和未注的「看着像数模」不是一回事。没有轮廓度，供应商按未注尺寸公差理解曲面，和装配干涉可以同时发生。

## 表面粗糙度

`Ra` 是轮廓算术平均，单位 µm。配合面、密封面、轴承挡肩要单独标。未注粗糙度写在图框里。

样块用手摸是对比，不是测量。关键面用来料的粗糙度仪，或在首件报告里看厂商的仪器读数。阳极、喷砂会改 Ra，检的是图上写的那一道工序之后，还是成品，要和尺寸一样冻死。

## 检测怎么排

首件把关键尺寸和关键形位做全。来料只抽这些关键项，外加螺纹通止和外观。全尺寸每一批都做，样机阶段通常做不到，所以关键项必须在图上圈出来，不能等 IQC 自己猜。

| 谁来测 | 适合 | 不要 |
|---|---|---|
| 来料卡尺、千分尺、通止规、千分表 | 尺寸、螺纹、架得起来的圆跳动 | 用卡尺判平面度、位置度、圆度 |
| 供应商或外协三坐标 | 位置度、轮廓度、圆柱度、垂直度 | 报告不写基准是 A/B/C 中的哪一个 |
| 综合量规 | 带 Ⓜ 的孔组 | 拿去检没有 Ⓜ 的位置度 |

报告至少写：图纸版本、基准、实测值或 Pass/Fail、仪器、是机加后还是表面处理之后。阳极会改变孔径和平面，机加后 Pass、阳极后不一定还在公差里。见 [CNC](./cnc.md)。

尺寸的标准测量温度是 **20 °C**。铝件刚下机就量，凉了会缩。有争议的孔，放凉再复测，不拿热件的数当让步依据。

## 冻结

- [ ] 图框里的未注线性、角度、未注形位各按哪一档
- [ ] 关键尺寸已圈出；其余不按「全图 ±0.02」
- [ ] 轴承孔、销孔、止口的配合代号，并注明对照哪份轴承样本
- [ ] 每个形位公差的基准是哪个装配面或孔
- [ ] 位置度有没有 Ⓜ，对应三坐标还是综合量规
- [ ] 圆跳动、垂直度的旋转基准是孔轴线还是外圆
- [ ] 表面处理前检还是成品检
- [ ] 粗糙度是机加纹路还是阳极 / 喷砂之后
- [ ] 首件报告和来料抽检各覆盖哪些项

## 验收

- 关键尺寸用能分辨该公差的量具。公差带小于量具分度，这颗料的尺寸判不了
- 形位报告的基准与图纸一致。基准用错了，整份位置度作废重测
- 螺纹通止规按规格，不看卡尺
- 跳动在图纸写的基准上复现一次。用手转、表针晃，不算
- 表面处理后的配合孔再检一次，或图上已写明机加尺寸含处理余量
- 3D 和 2D 不一致时，以冻结的 2D 公差为准，并升版。见 CNC 已知坑

## 已知坑

- 全图标成 ±0.02，价和交期一起上去，真要保证的轴承孔反而没有配合代号。
- 位置度没基准，供应商用最方便的边建坐标系，孔相对法兰是偏的，报告仍是 Pass。
- 用卡尺量平面度，或用打表一圈的结果去关圆度。
- 有 Ⓜ 的孔按没有补偿的三坐标判 Fail，能装的件被退。
- 没有 Ⓜ 的孔只用销子试装，销子过了就当位置度合格。
- 阳极前按 H7 合格，阳极后孔小，轴承压不进。
- 钣金孔距按机加位置度退货。折弯件的公差在 [折弯](./sheet-metal/bend.md)。
- 热的铝件当场判超差，凉了又回到公差里，来回让步。
