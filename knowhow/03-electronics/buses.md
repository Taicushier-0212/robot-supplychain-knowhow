# 总线

**大类：** [电子器件](./README.md)

机器人里的「总线」不是一根线的名字。采购要拆开三层：电气（差分还是单端、要不要终端电阻）、协议（报文、地址、周期）、连接器（能不能盲插、过不过关节）。只写「支持 CAN」或「有网口」，到货对不上。

运动控制那一层怎么用，见 [驱动器](../01-joint-modules/driver.md)。相机长线的座子见 [GMSL](./connectors/gmsl.md) 和 [视觉](../04-sensors/vision.md)。主控有没有主站见 [算力 / 主控](./compute.md)。

表上的速率是这一类的上限量级，不是关节里能稳定跑到的数。线一长、插头一多、旁边有电机，先掉的是裕量，不是标称 Mbps。

## 先看它该走多远

| 用在哪 | 用这些 | 不要拿来 |
|---|---|---|
| 同一块板上的芯片之间 | UART、I²C、SPI、I²S | 拉出壳体、过关节 |
| 关节和躯干之间的运动指令 | CAN / CAN FD、EtherCAT，或写清楚的私有协议 | UART、I²C、SPI 飞线 |
| 慢速、多点、要省线的传感器 | RS-485 加上一层协议 | 把 RS-485 本身当成协议 |
| 调试、U 盘、短外设 | USB | 活动长线、当运动总线 |
| 非实时的大量数据 | 以太网 | 以为有网口就等于 EtherCAT 主站 |
| 载板到算力模组、到 NVMe | PCIe | 做成拖链里的长电缆 |
| 板到板很短的相机、屏 | MIPI CSI / DSI | 过关节的软排 |
| 数米、要活动的相机 | GMSL、FPD-Link | 普通网线或 USB 线顶上 |
| 烧录和产测 | JTAG / SWD | 当成运行时的全身总线 |

全身运动指令尽量一种。电流环在驱动本地，比总线快；总线上的周期是目标更新率。见 [驱动器](../01-joint-modules/driver.md)。

## 板上

| | 是什么 | 采购时冻什么 |
|---|---|---|
| **UART** | 两根线，异步，点对点 | 电平是 3.3 V 还是 RS-232；波特率；谁是调试口。过板外要另加收发器 |
| **I²C** | 两根线，开漏，一条总线上多颗芯片靠地址 | 地址会不会撞；上拉在哪；速率是 100 kHz、400 kHz 还是 1 MHz。线长了上升沿变慢 |
| **SPI** | 时钟加数据，每颗从设备一根片选 | 模式（时钟极性和相位）、片选数、速率。没有统一插头，跨板要单独定义 |
| **I²S** | 音频数据，时钟跟着采样率和位宽 | 只出现在麦克风、功放。不要把它算进控制带宽 |

这四种默认不出关节。传感器若在肢端，改走 CAN、RS-485 或已经定好的运动总线。

## 整机控制

| | 是什么 | 口头速率 | 机器人里 |
|---|---|---|---|
| **CAN** | 差分，多节点，有仲裁 | 经典 CAN 短线最高 1 Mbps；全身常见 500 kbps 或 1 Mbps | 关节指令的默认之一。两端 120 Ω，支线要短 |
| **CAN FD** | 仲裁段仍按经典 CAN，数据段更快 | 数据段常见 2–5 Mbps，再高要看收发器和拓扑 | 和经典 CAN 不是同一颗收发器、同一套固件 |
| **RS-485** | 差分电气，半双工多点 | 短线收发器可以到数 Mbps；现场多为几十到几百 kbps | 必须再写协议，例如 Modbus RTU。只有 RS-485 等于还不能通信 |
| **EtherCAT** | 以太网物理层上的实时协议，报文在从站里边过边处理 | 物理层 100 Mbps；周期常见 1 ms，往下到几百 µs 要主站和从站一起证明 | 有 RJ45 不等于能当主站。主站在主控上还是外插卡，见 [算力](./compute.md) |

私有协议可以，但报文、单位、故障码、掉线行为、上位机要成套。口头能接 CAN、固件里没有对象，等于不能用。

CAN 的终端电阻是两只、装在总线两端，不是每一块板一只。多装或漏装，示波器上边沿发虚，表现为偶发掉帧。

## 通用外设

| | 是什么 | 口头速率 | 不要 |
|---|---|---|---|
| **USB 2.0** | 主机带从机，调试和 U 盘最熟 | 高速标称 480 Mbps | 当运动总线；活动段拉很长还指望不掉 |
| **USB 3** | 另一套差分对，头经常仍是同一外壳 | 5 Gbps 这一档起，看代数 | 和 USB 2.0 共用「一根 USB 线」的料号 |
| **以太网** | 交换机组网，走 IP 或其他上层 | 100 Mbps 或 1 Gbps | 把交换机抖动当成 EtherCAT 的周期 |

USB 要写清主机在主控还是在关节。从机口接到另一个从机上，两边都枚举不了。

## 板对板

**PCIe** 是载板和算力模组、NVMe、采集卡之间的通道。速率按代数：Gen3 每通道 8 GT/s 这一档，通道数 ×1 / ×4 要写在连接器上。金手指或板对板座子有插拔次数，不做成拖链电缆。

**MIPI CSI-2** 是相机进 SoC 的短链路，**DSI** 是到屏。软排线长度按厘米计，反复弯会断。过关节的相机改 GMSL 或 FPD-Link，不把 MIPI 排线加长。

## 相机长线

GMSL 和 FPD-Link 都是串行器 / 解串器：相机端把 MIPI 收进来，同轴或屏蔽双绞送出数米，主控端再解回 MIPI，线上还可以带控制和供电。

| | 谁家的链路 | 采购要拆开的 |
|---|---|---|
| **GMSL** | ADI（原 Maxim） | 代数、SerDes 料号、同轴还是 STP、座子。座子见 [GMSL 连接器](./connectors/gmsl.md) |
| **FPD-Link** | TI | 同样分芯片、线和座子。不能和 GMSL 对插 |

两边芯片必须是同一族、能互认的一对。只买「GMSL 相机」和「带解串的主控」，中间代数不一致，灯不亮。

## 烧录

**JTAG / SWD** 是调试和产线烧录。速率是几 MHz 到几十 MHz 的时钟，不拿来传图像或关节指令。图上要留口：针定义、复位、量产时测试点还在不在灌胶和外壳下面。灌胶盖住烧录口的坑见 [驱动器](../01-joint-modules/driver.md)。

## 冻结

- [ ] 运动总线只有一种：CAN、CAN FD、EtherCAT 或私有；周期和全身调度同一格
- [ ] 终端电阻、拓扑（总线型还是菊花链）、支线多长
- [ ] 私有协议的报文、单位、故障码、掉线行为
- [ ] RS-485 上面的协议名，不只写 RS-485
- [ ] USB 谁是主机；2.0 还是 3，线是不是同一料号
- [ ] 主控的 EtherCAT / CAN 主站是板载还是外插
- [ ] 相机：MIPI 只留在板边；过关节写 GMSL 或 FPD-Link 的芯片对
- [ ] PCIe 代数和通道数；连接器插拔次数
- [ ] 烧录口在成品上还进不进得去

## 验收

- 运动总线：按冻结周期跑满从站，拔掉一根后的行为与驱动器页一致，恢复后能再进运行
- CAN：两端终端电阻在，空载差分电压和波形边沿看过一次；多装终端时的偶发错误要能复现
- EtherCAT：主站认到的从站数量和顺序与接线一致，周期抖动有记录
- 相机：活动走线摆到工作角度再看丢帧，不只在台架直连时看
- 烧录口：用产测治具实际写进一次，不看「板上有排针」

## 已知坑

- I²C 拉到腿上，地址偶尔不应，被当成传感器坏。
- 经典 CAN 的固件去对 CAN FD 的驱动器，或反过来。
- 每一块关节板都焊 120 Ω，总线越长越不稳。
- 网口相机和 EtherCAT 共用「网口」这一个词，主站软件却只做了普通 UDP。
- USB 线和 USB 3 线料号混用，高速设备枚举成 2.0 或直接掉。
- MIPI 排线绕过肩关节，弯几次后丢帧。
- GMSL2 相机插到 GMSL1 解串上，连接器还能扣上。
- 灌胶或外壳把 SWD 盖死，小批改参数要拆关节。
