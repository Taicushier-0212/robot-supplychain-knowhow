# 算力 / 主控

**大类：** [电子器件](./README.md)

跑规划、视觉、全身调度的计算单元：工控机、边缘 AI 模组、核心板 + 载板、自研主板。不负责关节电流环——那是 [驱动器](../01-joint-modules/driver.md)。

只看「多少 TOPS」不够下单。接口、供电、散热、镜像和总线主站能力没冻，到货就是一台能开机的砖。

下文 TOPS / 核数 / 功耗是 **厂家宣传或常见样本口径**，用来分档，不代替目标板上的实测帧率。稀疏 INT8、稠密、不同工具链之间的数字不要横比成「算力倍数」。

## 在机器人里干什么

| 它管 | 它不管 |
|---|---|
| 轨迹与步态规划、全身协调 | 关节电流环、换向 |
| 视觉 / 力觉感知融合、推理 | 减速器、编码本身 |
| 总线主站（EtherCAT / CAN 等）发周期指令 | PACK 成组与 BMS 保护细节 |
| 日志、遥控、上位调试通道 | 母线预充与大电流配电 |

和驱动的咬合看 **总线周期、同步方式、掉线行为**，不要只对「有没有这个口」。相机带宽、算力峰值和供电峰值会叠在一起，见 [电源模块](./power.md)、[线束](./harness.md)。

## 先分清买的是什么

| 形态 | 是什么 | 选型时盯住 |
|---|---|---|
| **整机工控 / 盒子** | 带壳、电源、常用口已引出 | 抗振、安装、风扇策略、长期供货 |
| **核心板 / SOM / Module** | SoC 周边焊死，口在载板上 | 模组型号 + 载板谁做；针座与供货 |
| **开发板 / 套件** | 开箱即用的评估板 | 样机可以；量产要问工规与锁料 |
| **自研主板** | 芯片级贴片 | BSP、散热、EMC、改版周期 |

口头「一块 RK3588 / 一块 Orin」可能是芯片、模组或整机。PO 写清 **平台系列 + 具体型号 + 内存 / 存储 + 形态**。

## 选型轴（所有主控通用）

### 算力与软件

- [ ] CPU 架构与核数；是否需要实时核 / MCU 域
- [ ] NPU / BPU / GPU 算力及 **框架**（RKNN、Horizon、TensorRT、ONNX…）
- [ ] 内存容量与带宽；是否可换颗粒
- [ ] 存储：eMMC / NVMe / SD；镜像与 OTA
- [ ] 目标 OS、内核、是否要实时补丁

### 接口与总线

- [ ] 运动总线：EtherCAT 主站 / CAN / CAN-FD——**板载还是外插**
- [ ] 相机：MIPI 路数与线长；USB3；网口速率
- [ ] PCIe：网卡、采集、SSD 是否抢通道
- [ ] 调试口：HDMI / DP、USB、UART、40-pin 等

### 供电、热、结构、供货

- [ ] 输入电压、峰值电流、上电时序
- [ ] 功耗档与降频温度；封闭躯干散热余量
- [ ] 安装尺寸、抗振、出线方向
- [ ] 停产策略、第二货源、BSP 谁维护

## 平台怎么先分大类

| 家族 | 是谁 | 机器人里常见角色 |
|---|---|---|
| **RK（瑞芯微）** | SoC 系列，买芯片 / 核心板 / SBC | 成本敏感主脑或视觉副脑；RKNN 栈 |
| **RDK（地瓜 / D-Robotics）** | 基于旭日等芯片的开发板与模组 | 机器人视觉原型、BPU 推理；TROS 生态 |
| **Jetson Orin** | NVIDIA Orin 模组族（Nano / NX / AGX） | CUDA / TensorRT 视觉与具身模型 |
| **Jetson AGX** | NVIDIA 的 AGX 外形与高端档（含 Xavier AGX 旧档、AGX Orin） | 高算力主脑、多传感器融合 |

RK / RDK 偏国产边缘与机器人套件；Orin / AGX 偏 NVIDIA 生态。软件栈和主站方案往往比「TOPS 数字」更决定能不能上机。

## RK 全系列（瑞芯微）

瑞芯微应用处理器。人形 / 边缘里常谈的是 **RK3588 档、RK3576 档、RK3568 档**，再往下是老平台。买的是 **芯片型号 + 核心板厂家型号**，不是口头「一块 3588」。

### 档位对照（样本口径）

| 型号 | CPU（约） | NPU | 内存总线（约） | 机器人里怎么用 |
|---|---|---|---|---|
| **RK3588** | 4×A76 + 4×A55 | ~6 TOPS | 64-bit，容量天花板高 | **当前默认高端 RK**：多路相机 + 轻量推理 + 调度 |
| **RK3588S / 衍生** | 同族裁剪 | 看具体衍生 | 接口/封装有裁 | 必须写清后缀，不能和 3588 混料 |
| **RK3576** | 4×A72 + 4×A53 | ~6 TOPS | 32-bit | 中高端性价比；NPU 接近 3588，CPU/GPU/接口弱一档；部分型号带 **CAN FD** |
| **RK3568** | 4×A55 | ~1 TOPS | 32-bit | 工控、网关、轻视觉；当不了重推理主脑 |
| **RK3566** | 4×A55 | ~1 TOPS 级 | 更消费向 | 平板/显示类多；机器人量产少作主控 |
| **RK3399** | 2×A72 + 4×A53 | 无独立 NPU | 老平台 | 存量项目；新开机器人主控一般不选 |
| **RK3288 等更早** | 更老 | 无 / 极弱 | — | 维护件，不进新选型 |

数字会随手册修订，下单以该颗芯片 / 该块核心板数据手册为准。

### 怎么选 RK

```text
多路相机 + 要 NPU + 要扩展（PCIe/多网口）
  → RK3588 核心板（写清厂家型号与内存）

要接近 6 TOPS、预算和功耗更紧、接口要求没那么满
  → 评估 RK3576；确认 CAN FD / MIPI / PCIe 是否够用

轻逻辑、HMI、低算力网关
  → RK3568 可能够；不要用 3568 硬扛多路深度模型

老项目 RK3399
  → 维持可以；新开优先 3576/3588
```

### RK3588 细说

8 核（4×A76 + 4×A55）、Mali-G610、片内 NPU ~6 TOPS，MIPI / 显示 / PCIe 资源在 RK 里最满，是人形里最常见的 RK 档。

**适合：** 全身调度、中等视觉、核心板 + 自定义载板从样机到小批。  
**不单独解决：** 电流环；「有网口 = EtherCAT 主站」；大模型满血端侧（要实测）。

冻结字段：3588 还是 3588S；核心板品牌型号；LPDDR / eMMC；MIPI 路数；网口与 PCIe 是否留给主站卡；供电；Linux 镜像与 RKNN 版本。

### RK 常见坑

- 只写「RK3588」，到货 3588S 或杂牌核心板，设备树全改。
- 3576 与 3588 都宣传 6 TOPS，当成同性能——CPU、GPU、内存带宽差一截。
- 3568 当视觉主脑，NPU 和带宽先爆。
- 开发板供电座、散热焊盘按量产用。

## RDK 全系列（地瓜 / D-Robotics）

**RDK** = D-Robotics Developer Kits（地瓜机器人开发者套件），芯片侧是旭日等平台，软件侧常配 **TogetheROS.Bot（TROS）**。和「买一颗 RK 芯片自己贴」不是一条供应链：这里买的是 **开发板 / Module / 套件**，接口和镜像以地瓜文档为准。

TOPS 为 BPU 等效宣传值，型号迭代快，下单核对官方当前手册。

### 档位对照（口头）

| 产品 | 算力口径（约） | CPU（约） | 形态 | 机器人里怎么用 |
|---|---|---|---|---|
| **RDK X3** | ~5 TOPS | 4×A53 | 开发板 | 入门视觉、课程、轻量原型 |
| **RDK X3 Module** | 同 X3 档 | 同左 | 核心模组（近似 CM4 尺寸生态） | 定制载板、紧凑机身 |
| **RDK X5** | ~10 TOPS | 8×A55 | 开发板 | **当前主流机器人视觉开发板**；多 USB3、CAN FD、双 MIPI 等 |
| **RDK X5 Module** | 同 X5 档 | 同左 | 核心模组 | 产品化载板；口由载板决定 |
| **RDK Ultra** | ~96 TOPS | 8×A55 级 | 高算力套件 | 多摄、较重感知；注意热与供电 |
| **RDK S100 / S100P** | ~80 / ~128 TOPS 档 | 异构机器人套件 | 高集成开发套件 / SIP | 更高端具身与多传感器；核对接官方生命周期 |
| **RDK S600 等更新档** | 更高算力宣传 | 具身智能套件 | 新系列 | 以发布时官方规格为准，勿抄旧表 |

开发板上的 RJ45、USB-A、相机座 **不等于** Module 原生脚；Module 的最大原生资源也不等于载板一定全引出。

### 怎么选 RDK

```text
快速搭视觉原型、要 TROS 示例
  → RDK X5 开发板（入门可用 X3）

结构已定、要塞进壳体
  → X3/X5 Module + 自研载板；冻连接器与散热

多路相机 / 更重模型
  → Ultra 或 S100 档；先热设计与供电，再谈算法

和 RK3588 比
  → RDK 强在机器人套件与 BPU/TROS；RK 强在通用核心板货源与载板生态。栈不同，别只比 TOPS
```

### RDK 常见坑

- 把 X3 开发板当量产主板，接口与供货生命周期不够。
- X5 板载口写进 Module 规格书，载板没做出来。
- 忽略降频温度，封闭机身 BPU 跑一阵就掉帧。
- 和 RKNN / TensorRT 模型不通用，迁移工时没进计划。

## Jetson Orin 全系列（NVIDIA）

Orin 是 NVIDIA 边缘机器人里的一代 SoC 族，按模组分成 **Orin Nano / Orin NX / AGX Orin**。共用 CUDA / TensorRT 生态；差在 GPU 规模、CPU 核数、内存带宽、DLA、功耗与外形。

下列 AI 性能多为 **稀疏 INT8 峰值**；部分 Nano 还有 Super 模式抬频，数字会高于初版手册——PO 写清模组料号与功耗模式。

### 档位对照（常见样本口径）

| 模组 | AI 性能（约） | CPU（约） | 内存（约） | 功耗档（约） | 定位 |
|---|---|---|---|---|---|
| **Orin Nano 4GB** | ~20–34 TOPS | 6×A78AE | 4GB | 7–15/25 W 档 | 入门视觉、低功耗 |
| **Orin Nano 8GB** | ~40–67 TOPS | 6×A78AE | 8GB | 同上 | 入门偏上；无 DLA |
| **Orin NX 8GB** | ~70–117 TOPS | 6×A78AE | 8GB | 10–25/40 W 档 | 小外形主力；有 DLA |
| **Orin NX 16GB** | ~100–157 TOPS | 8×A78AE | 16GB | 同上 | 小外形高配 |
| **AGX Orin 32GB** | ~200 TOPS | 8×A78AE | 32GB | 15–40 W 档 | 高算力；见下节 AGX |
| **AGX Orin 64GB** | ~275 TOPS | 12×A78AE | 64GB | 15–60 W 档 | 旗舰模组 |
| **AGX Orin Industrial** | ~248 TOPS | 12×A78AE | 64GB+ECC | 更高环境规格 | 工规、ECC、温度与寿命口径不同 |

Nano / NX **模组上通常无 eMMC**，系统盘多在载板 NVMe；AGX Orin 模组常带 eMMC。载板（carrier）决定网口、相机座、电源座——**模组名 ≠ 整机接口清单**。

### 怎么选 Orin

```text
功耗紧、模型轻、要 CUDA 起步
  → Orin Nano 8GB（4GB 只做很轻的验证）

要塞进小壳体、还要认真跑视觉
  → Orin NX 16GB 优先；8GB 看模型与并发

多路传感 + 大模型 / 重融合
  → AGX Orin 32/64GB；热和电池一起算

工业温度、ECC、长供货
  → AGX Orin Industrial，不要用消费模组顶
```

### Orin 常见坑

- Nano 与 NX 外形接近，按 NX 热设计装 Nano 无所谓，反过来 NX 会降频。
- 只锁「Orin」，不锁 4/8/16/32/64GB 与 Super 模式。
- 开发套件当量产：载板、供电、抗振都要另冻。
- 有 GPU 仍缺 EtherCAT 主站方案——和 RK 一样要单独验证。

## Jetson AGX 全系列（NVIDIA）

**AGX** 在 NVIDIA 语境里主要指 **大外形、高带宽内存、高算力** 那一档模组，不是与 Orin 平行的另一套芯片命名。当前主力是 **AGX Orin**；上一代是 **AGX Xavier**。口头「上 AGX」要问清是 Orin 还是 Xavier 残留库存。

### AGX Orin（当前）

| 型号 | 要点 |
|---|---|
| **AGX Orin 32GB** | 8 核 CPU、较大 GPU、32GB 256-bit LPDDR5；高性能主脑常用起点 |
| **AGX Orin 64GB** | 12 核、更大 GPU、64GB；峰值约 275 TOPS 档；热与供电最紧 |
| **AGX Orin Industrial** | 面向工业：ECC、温度与可靠性口径更严；算力数字接近但 **不能按消费 64GB 互换** |
| **AGX Orin Developer Kit** | 官方开发套件；样机评估用，量产仍要模组 + 载板 / 工规盒 |

AGX 相对 Orin NX：同代算力与内存带宽更高，体积、功耗、成本也更高。躯干装得下、电池扛得住再上；否则 NX + 算法裁剪往往更现实。

### AGX Xavier（上一代，存量）

| 型号 | 要点 |
|---|---|
| **AGX Xavier / Xavier Industrial** | Volta 代；算力与生态旧于 Orin |
| **Xavier NX** | 不是 AGX 外形，但是同代小模组；迁移时常被一起提到 |

新开项目默认 **Orin 族**。Xavier 只用于：产线已冻结、证书未改、或明确消化库存。软件与 TensorRT 版本不要和 Orin 混为一谈。

### AGX 怎么选

```text
新项目要 NVIDIA 旗舰主脑
  → AGX Orin 32GB 起评；不够再上 64GB

要工规 / ECC
  → AGX Orin Industrial

仓库里还有 Xavier AGX
  → 可维持；新 BOM 不要和无差别 Orin 混用同一镜像
```

### AGX 常见坑

- 「AGX」只写到系列，32/64/Industrial 乱到货。
- 开发套件功耗曲线当整机电池预算。
- Xavier 与 Orin 载板 / 镜像混用。
- 算力上了 AGX，相机与总线载板仍按 Nano 级设计，IO 先成为瓶颈。

## 四条产品线怎么横比（选型用，不是跑分）

| | **RK** | **RDK** | **Orin Nano/NX** | **AGX Orin** |
|---|---|---|---|---|
| 生态 | RKNN、通用 Linux 核心板 | TROS / 地瓜 BPU | CUDA / TensorRT | 同左，更高配 |
| 成本 | 相对低 | 套件价，看档位 | 中高 | 高 |
| 典型角色 | 调度 + 中等视觉 | 机器人视觉原型 / 产品模组 | 主流 NVIDIA 边缘 | 重感知旗舰 |
| 主站 | 常外加 | 看板载 CAN 等，EtherCAT 仍要验 | 常外加 | 常外加 |
| 热 | 封闭机身要做 | 高档更烫 | NX 已要紧 | 最要紧 |

没有「全能第一」。先冻软件栈和接口，再冻系列与料号。

## 验收要点

- 冷启动、掉电重启、看门狗
- 外设枚举：网口、USB、相机、总线主站
- 持续满载（CPU + NPU/BPU/GPU + 相机）温升与是否降频
- 总线周期抖动（有主站时）
- 丝印 / 料号 / 镜像与订单一致

## 已知坑

- 只看 TOPS，接口不够当主站或相机不够路。
- 散热按桌面测，装进封闭躯干过热降频。
- 样品与小批换模组厂家或换衍生型号，驱动全改。
- 主控与驱动器共地、共电源不清，总线一接就复位。
- 相机和电机动力线绑在一起，视觉误码当「算力不够」。
- RK / RDK / Jetson 模型与工具链不互通，切换平台当「换一块板」。
