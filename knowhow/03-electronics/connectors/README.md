# 接插件

**大类：** [电子器件](../README.md)

可拆的电连接。键位、锁扣、载流和针的镀层决定能不能反复拆。线径和绝缘见 [线材](../wire/README.md)，做成电缆见 [线束](../harness.md)。

| 页 | 讲什么 |
|---|---|
| [XT30（2+2）](./xt30.md) | 动力 2 针 + 信号 2 针；名字里的 30 不是持续电流 |
| [GMSL 连接器](./gmsl.md) | 相机串行链路的座子与线；常和 FAKRA 一起冻，别和芯片代数混 |

## 选型时先分场景

| 场景 | 常见方向 | 不要 |
|---|---|---|
| 关节要同时走动力和一对信号，电流在 XT30 动力针能力内 | **XT30（2+2）** | 用信号针分担动力电流 |
| 只有动力、电流更高 | XT60 / XT90 等，持续电流以规格书为准，不看名字里的数字 | 把 XT60 当 60 A 持续 |
| 三相电机相线 | 三针动力插头（如 MR30 一类），和两针电池头分开 | 用 XT30 两针凑三相 |
| 板端小信号、不走动力 | JST、板对线小间距 | 和电池头做成同一种外形 |
| 头舱 / 外置相机，比 MIPI 更长、要同轴串行 | **GMSL + FAKRA（或项目规定的高速头）** | 用 USB 线或普通视频头顶；只写 GMSL 不写座子型号 |

尽量少种类。电源和调试口外形接近时，必须靠键位物理防呆。

## 选型必须冻结

- [ ] 完整型号，含针数、公母（写成 **针 / 孔**）、镀层  
- [ ] 动力针和信号针各自的载流、电压，不看商品名里的数字  
- [ ] 线号能否焊进或压进杯口。见 [AWG](../wire/awg.md)  
- [ ] 锁扣还是摩擦配合；振动下要不要热缩、扎带  
- [ ] 对插次数  
- [ ] 电源侧用孔式触点，避免裸针短路  
- [ ] 国产替代要做保持力和温升，不接受「能插上」  

## 坑

- 替代料能插，保持力不够，振动后虚接。  
- 公母各家叫法相反，按照片采购插反或插不进。  
- 名字带 30、60、90 被当成持续安培。  
- GMSL、FAKRA、线缆三代不同事，只锁其中一个。
