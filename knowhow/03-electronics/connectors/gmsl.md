# GMSL 连接器

**大类：** [电子器件](../README.md) · **小类：** [接插件](./README.md)

**GMSL**（Gigabit Multimedia Serial Link，Maxim / ADI 系）是车载与机器人里常见的 **相机串行链路**：相机端 Serializer、主控端 Deserializer，中间走同轴或屏蔽双绞，把 MIPI / 并行视频、控制（I²C 等）和供电挤在一根线上。

采购口头说「GMSL 头」，常常混了三件事，PO 要拆开写：

| 层级 | 是什么 | 不要 |
|---|---|---|
| **链路 / 芯片** | GMSL1 / GMSL2 / GMSL3，具体 SerDes 料号 | 只写「支持 GMSL」不写代数与对端芯片 |
| **线缆** | 同轴（常见 50 Ω）或 STP；阻抗、衰减、外径 | 用普通 USB 线或网线顶 |
| **连接器** | 板上座 + 线端头；车载默认多为 **FAKRA / Mini-FAKRA** 一类射频同轴头 | 把 USB-C、航插和 GMSL 当成同一种头 |

本页管 **连接器与对插**。相机规格见 [视觉](../../04-sensors/vision.md)；主控侧有没有解串口见 [算力 / 主控](../compute.md)。

## 在机器人里干什么

头、胸、腕外置相机要 **比 MIPI 排线更长**、又比千兆网相机更省协议栈时，常用 GMSL：一根同轴过关节或过壳，板端解串再进 SoC 的 MIPI / 采集。

MIPI 软排线适合板到板很短；USB3 长线在活动段易掉帧、EMI 难做；网口相机要交换机与带宽预算。GMSL 不是万能，但是「几米级、活动、多路相机」里很常见的一条。

## 常见物理头（别和芯片代数绑死）

同一代 GMSL 芯片可以配不同座子；座子选型看整机标准和线厂，不看「听说 FAKRA 才能跑 GMSL2」。

| 类型 | 特点 | 机器人里 |
|---|---|---|
| **FAKRA** | 塑料壳 + 同轴芯，颜色/键位分码，车载默认 | **最常见**；要冻颜色码与公母 |
| **Mini-FAKRA / HFM 等** | 更小、可多联排 | 头舱空间紧、多路相机并排 |
| **HSD（高速数据头）** | 差分/高速座，外观不像普通 FAKRA | 部分模组线束；不能和 FAKRA 混插 |
| **板端同轴座 / MMCX 一类** | 小板、样机 | 振动与反复插拔要另验；量产少当默认 |
| **航插转 GMSL** | 外壳用圆形航插，里面仍是同轴芯或转接线 | 只解决防护与安装，**芯线阻抗和衰减仍要按 GMSL 冻** |

公母、颜色键位、螺纹/卡扣各家习惯不同。写成 **针/孔 + 颜色码 + 完整型号**，不写「FAKRA 公头」。

## GMSL1 / 2 / 3 和头的关系

| 代数（口头） | 选型时盯住 |
|---|---|
| GMSL1 | 较老；带宽与功能少；存量相机要对得上解串 |
| GMSL2 | 当前机器人 / 车载很常见；单向视频 + 反向控制通道 |
| GMSL3 | 更高带宽、更多路；芯片、线、座都要按该代手册 |

**连接器代数 ≠ 链路代数。** FAKRA 既能跑旧链路也能跑新链路；冻的是 SerDes 料号、线规、长度与座子型号，不是「买了 FAKRA 就等于 GMSL2」。

PoC（同轴供电）是否启用、电压与电流，写在电源与相机页，不要默认「一根同轴一定带电」。

## 选型必须冻结

- [ ] 链路：GMSL1 / 2 / 3；相机端与主控端 **SerDes 完整料号**（必须配对）
- [ ] 介质：同轴还是 STP；阻抗（同轴常见 50 Ω）；最大线长与弯曲次数
- [ ] 连接器完整型号：板端座、线端头、颜色码 / 键位、公母（针/孔）
- [ ] 是否 PoC 供电；电压、电流、反接与短路保护在哪侧
- [ ] 路数与同步：几路相机、触发/帧同步怎么走（链路上还是另线）
- [ ] 活动段：过关节外径、最小弯曲半径、是否要拖链级线
- [ ] 屏蔽与接地：壳地、信号地在头舱怎么接，避免和电机动力线共绞
- [ ] 替代线束：插得上不算合格，要过眼图 / 误码或厂商认可的长度表

## 配套关系

- [视觉](../../04-sensors/vision.md)：分辨率、帧率决定链路带宽够不够；镜头与标定另冻。  
- [算力 / 主控](../compute.md)：解串后进 MIPI / PCIe 的通道数；和 EtherCAT 主站抢带宽时要一起算。  
- [线束](../harness.md)：活动段长度、固定点、与动力线间距；断芯时座子往往还是好的。  
- [电源](../power.md)：PoC 峰值与母线跌落；头舱多路同时上电。

## 验收要点

- 座子型号、颜色码与对插图一致；反插插不进  
- 轻拉线缆，芯线与壳不脱；卡扣到位有手感  
- 上电出图：目标分辨率与帧率下连续跑，看丢帧与花屏  
- 活动段按关节行程弯折若干次后再测（样机至少做）  
- PoC：电压、电流、相机端纹波在冻结范围内  
- 与大电流动力线并行时的干扰：电机峰值运动下是否误码

Fail：颜色码能插但针定义相反；用普通视频同轴或不控阻抗的线；只验静态出图、不验活动弯曲。

## 已知坑

- 只写「GMSL 相机」，不解串芯片与主控是否一对。  
- USB 相机改 GMSL，结构还按 USB-C 开孔。  
- FAKRA 颜色看起来差不多就互插，键位不同或定义不同，烧口或无图。  
- 线长按「网线 100 m」心理点货，GMSL 按芯片与线规的衰减表，超长先花屏。  
- 头舱把 GMSL 和电机相线绑成一束，运动时丢帧当「主控不够」。  
- 样品手工头，小批换廉价座，驻波和保持力都变，间歇性花屏难查。  
- 以为换 FAKRA 就升级到 GMSL3——代数在芯片，不在塑料壳。
