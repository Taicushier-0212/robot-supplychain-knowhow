# PCB / SMT

**大类：** [电子器件](./README.md)

**裸板**是没有器件的印制板。**PCBA** 是贴完、焊完的板。两张单、两次来料，不要在一张 PO 里写成「打板」就以为含贴片，也不要把贴片厂当板厂。

关节内驱的功能规格在 [驱动器](../01-joint-modules/driver.md)。电感编码器的线圈板是另一类工艺，见 [电感编](../01-joint-modules/encoder/inductive.md)，不要套用下面的 FR-4 驱动板口径。

## 在机器人里干什么

关节外置驱动、传感器转接、躯干配电、通讯底板。板要能装进壳体、插头方向和 [线束](./harness.md) 出线一致，功率回路的热要有地方进壳体。

原理图、BOM、板厂叠层确认之前不打正式板。样品可以打，但样品叠层和表面处理要写进记录，不能默许小批「照样品」。

## 层数、板厚、铜厚

| | 口头怎么用 | 不要 |
|---|---|---|
| **2 层** | 低速转接、没有完整地平面的要求 | 电机驱动、USB、以太网当默认 |
| **4 层** | 驱动、MCU、CAN 的默认：外层走线，内层电源和地 | 只加层数、不规定哪一层是地 |
| **6 层及以上** | 阻抗、密脚 BGA、功率和信号抢同一层时 | 没算过叠层就升层 |
| **板厚** | 1.6 mm 最常见；关节里薄到 1.0 / 0.8 mm 要单独写 | 连接器插拔力打在 0.8 mm 板上还不加固定 |
| **铜厚** | 1 oz ≈ 35 µm，信号默认。功率回路外层口头常要 **2 oz（约 70 µm）** | 只写「加粗走线」不写铜厚 |

载流看线宽 **和** 铜厚 **和** 温升，按 IPC-2152 或板厂计算冻结，不在图上写「能过 10 A」。内层铜散热差，同样线宽载流低于外层。

过孔孔径、孔铜、环宽按选定板厂的能力冻。盲孔、埋孔、盘中孔是另一档价格和周期，正式单上要出现这几个字，不能只在 Gerber 里藏着。

## 基材

默认 **FR-4**。玻璃化温度 Tg：普通板约 130–140 °C；无铅回流、贴在电机或壳体温升旁边的板，口头要 **高 Tg（170 °C 级）**。Tg 不是长期工作温度，只说明板子在回流和局部受热时不容易发软。

纸基板（CEM-1 一类）不进关节和驱动。

铝基板是另一条工艺，用来把热量从功率器件铺到铝底，不能当普通 FR-4 的「加厚版」去报价。

软板、软硬结合只用在过中空、要弯一次或反复弯的地方。要另冻：弯折半径、补强在哪、覆盖膜（不是绿油）、连接器是否落在硬区。软板泡在减速器油脂里会分层，密封和软板是一件事。

## 表面处理

焊盘表面决定能不能贴细间距、能放多久。

| 处理 | 特点 | 机器人里 |
|---|---|---|
| **有铅喷锡** | 便宜、焊盘不平整 | 新板不用。无铅回流不要混有铅 |
| **无铅喷锡** | 便宜，表面起伏 | 间距宽、没有 BGA / 0.5 mm 及更细的脚 |
| **沉金 ENIG** | 平整，适合细间距和按键金面 | **驱动板、主控、细间距连接器的默认**。要冻镍厚和金厚，不要只写 ENIG |
| **OSP** | 最便宜，铜上有机膜 | 尽快贴。库存口头按月计，拆包后更短。超期不要硬贴 |
| **电硬金** | 厚、耐磨 | 反复插拔的金手指。普通焊盘不要整板硬金 |

沉金的镍层常见数微米，金层是零点几个微米这一档（规格书常按微英寸写）。金太厚焊点发脆，太薄焊盘发暗。厚度以板厂可保证的规格冻死。

## 阻抗

要控阻抗的网在图上点名，并附上 **这家板厂** 的叠层（介质厚度、介电常数、铜厚），不是网上一份通用四层叠层。

口头目标，短走线多数可以不控，长走线或连接器之间要控的才写进订单：

| 信号 | 常见目标 |
|---|---|
| USB 2.0 差分 | 约 90 Ω |
| 以太网差分 | 约 100 Ω |
| 板上短 CAN | 多数不控；电缆侧 120 Ω 是线束的事 |

阻抗公差口头常见 **±10%**，用板边试焊条（coupon）验收，不拿成品板去刮阻焊猜线宽。板厂一换，叠层就作废，阻抗要重算，不能沿用上一家的线宽。

## 出图包

一个硬件版本一套文件，文件名里带版本号：

- Gerber、钻孔、板框
- 叠层和阻抗表（需要控的才有）
- BOM：厂家料号，不写「10 µF」就完
- 坐标文件、装配图，**1 脚**在丝印和装配图上一致
- 钢网层与这个 Gerber 版本对应
- 有 MCU 时：烧录接口、固件版本、板号怎么读出来

丝印上的 **硬件版本** 和固件版本是两个数。改一颗电阻是新硬件版本，不是「跟上一批差不多」。

## 贴片

- 单面还是双面。双面回流要写哪一面先贴，重的连接器不要悬在第二次回流的背面。
- 插件（功率端子、大电容）是波峰、选择焊，还是后焊。后焊的热不能烫到旁边已贴的细脚。
- QFN、BGA 底下的过孔要阻焊盖住，否则锡被吸走，焊点空。
- 拼板：工艺边、三个基准点（fiducial）。**V 割不要切过连接器和陶瓷电容**；靠近器件用邮票孔。
- 湿敏器件按 MSL 等级拆包、烘烤。烘烤温度不能超过器件和托盘能受的。
- 三防：涂哪里、不涂哪里。接插件、测试点、散热焊盘、要壳接地的露铜不涂。涂完再插拔，涂层会进针孔。
- 替代料要有 AVL。不在 AVL 里的料是新版本，不是贴片厂「同等」。

长周期芯片在 G0 标红。见 [成本与交期](../../docs/cost-leadtime.md)。结构件齐了、驱动芯片还要十来周，板就停在空贴。

## SMT / PCBA 检测（SPI / AOI / X-Ray / ICT / FT）

贴片产线检测不要只写「测试合格」。各道查的东西不同，**不能互相替代**。量产常见顺序：

```text
SPI（锡膏）→ 贴片 → 回流前 AOI（可选）→ 回流 → 回流后 AOI
  → X-Ray / AXI（BGA、QFN 等）→ ICT（在线）→ FT/FCT（功能）→ 必要时老化
```

插件、选择焊、后焊还有自己的目检 / AOI；三防最好在电测通过之后，避免测试点被盖死。

### SPI（Solder Paste Inspection，锡膏检测）

回流 **之前** 查钢网印刷：锡膏体积、高度、面积、偏移、桥连倾向。

- **能抓：** 少锡、多锡、漏印、钢网堵孔、印刷偏移——很多虚焊/连锡的根在这里。  
- **不能代替：** 贴片对错、回流后焊点、功能。  
- 冻结：要不要 SPI、全检还是抽检；与钢网版本绑定。

### AOI（Automated Optical Inspection，自动光学检测）

用相机 + 算法看 **外观**：有料没料、极性、偏移、立碑、连锡、少件、部分侧立脚焊点。分 **回流前**（贴装位置）和 **回流后**（焊后外观）；量产至少要明确 **回流后 AOI**。

- **能抓：** 错料外形差大、反贴（有丝印/极性特征时）、连锡、立碑、明显少件。  
- **不能代替：** BGA 底面、QFN 底焊盘虚焊、电气开短路、功能。  
- **误报 / 漏报：** 程序阈值太松漏缺陷，太紧产线全是假 Fail；换料外形变了程序要重教。  
- 冻结：回流前/后哪几道 AOI；覆盖料号；误报复核流程；报告是否随批次。

目检（人工显微镜）只能补 AOI 抽不到或争议项，不能当量产唯一手段。

### X-Ray / AXI（X 光检测）

穿透封装看 **看不见的焊点**：BGA 球、QFN/LGA 底焊盘、部分屏蔽罩内。

- **能抓：** 空洞超标、桥连、少球、严重虚焊形态（按双方判据）。  
- **不能代替：** 开路网络级覆盖（仍要 ICT）、功能。  
- 冻结：哪些封装必须 X-Ray；全检还是抽检比例；空洞率判据（不要口头「看起来还行」）。

口头 AXI = 自动 X 光；和 AOI 不是同一台设备。

### ICT（In-Circuit Test，在线测试）

测 **器件有没有装对、焊通**，偏网表 / 元件级：开短路、阻容二极等、部分供电与关键网络。针床或飞针。

- **能抓：** 贴装与焊接导致的电气问题，节拍快。  
- **不能代替：** 固件逻辑、时序、整机功能。  
- 裸板飞针 / 网表 ≠ PCBA 的 ICT：前者光板，后者贴完的板。

### FT / FCT（Functional Test，功能测试）

测 **按设计能不能干活**。口头 FT、文件写 FCT，通常一回事：上电、烧录、用例、通信枚举、关键带载。

- **能抓：** 不起机、功能项 Fail、部分参数问题。  
- **代价：** 夹具与程序贵，节拍常慢于 ICT。

### 老化 / 其它（按产品加）

高可靠或现场难返修的板：高温老化、温循、通电拷机。不是每块消费板都要；要做就冻温度、时间、通电负载与 Fail 判据。

### 一道表看清

| 工序 | 问什么 | 典型抓 | 替不了谁 |
|---|---|---|---|
| **SPI** | 锡膏印对了吗 | 少锡多锡、偏移 | 贴装与功能 |
| **AOI** | 看起来装对了吗 | 少件、极性、连锡、立碑 | BGA 底面、电气功能 |
| **X-Ray** | 底面焊点怎样 | 空洞、桥连、少球 | 全网表、功能 |
| **ICT** | 电路通吗、料对吗 | 开短路、错阻容 | 功能与固件 |
| **FT** | 能干吗 | 不起机、通信失败 | 底面虚焊全覆盖 |

### 检测相关冻结

- [ ] SPI：做不做；与钢网版本  
- [ ] AOI：回流前/后；程序版本与硬件版本绑定  
- [ ] X-Ray：哪些封装、抽检比例、空洞判据  
- [ ] ICT：针床/飞针；覆盖网与料号  
- [ ] FT：用例、固件版本、Pass/Fail  
- [ ] 全检还是抽检；报告随批次出什么  
- [ ] 测试点是否被三防盖住；夹具与本硬件版本一致  

Fail：只写「AOI+电测 OK」；AOI 过了当 BGA 免 X-Ray；FT 过了省 ICT；程序未随改版更新仍报 Pass。

## 验收

**裸板**

- 板厚、翘曲、绿油、丝印版本
- 表面处理与订单一致，OSP 看生产日期
- 飞针或同等网表测试，开路短路有报告
- 有阻抗要求的，coupon 在公差内

**PCBA**

- 防静电包装
- 丝印版本、极性、1 脚、没有立碑、连锡、少件
- 约定 AOI 的：有批次/抽检记录，重大缺陷项可追溯
- QFN / BGA：约定 X-Ray 的按判据出报告，或双方同意的替代手段
- 约定 ICT 的：开短路 / 错料项可追溯
- 约定 FT 的：按冻结用例 Pass；固件版本读出来和本批一致
- 限流上电：静态电流、电源轨、枚举（可并在 FT 里）
- 功率接口能带额定电流，温升有记录
- 连接器对插、轻拉不掉盘

Fail：焊盘发黑仍贴、钢网版本对不上 Gerber、样品料号和小批不同、测试点被三防盖死、只报「测试合格」无区分 SPI/AOI/X-Ray/ICT/FT。

## 已知坑

- BOM 未冻就打板，贴完飞线。
- 样品一套料，小批贴片厂换「同等」，驱动时序变了。
- 细间距用喷锡，脚间锡少锡多，AOI 过后上电短路。
- OSP 在仓库放过季，贴上去虚焊，看起来像设计问题。
- 只写 4 层，不附叠层，换板厂后 USB 眼图不过。
- 1 oz 外层走电机电流，铜皮发黄、阻焊鼓起。
- V 割从陶瓷电容底下过，运输后电容裂，时好时坏。
- 连接器只有焊盘固定，插拔几次焊盘掀起。0.8 mm 板更明显。
- 三防进了 XT30 或板对板连接器，接触电阻变成随机故障。
- 软板当普通 FR-4 报价，交期和弯折次数都对不上。
- 以为 FT 过了就不用 ICT，量产虚焊漏到整机。
- ICT 夹具还是旧硬件版本，新板测试点挪了仍报 Pass。
- AOI 程序太松，连锡漏到整机；太紧产线假 Fail 把真缺陷淹没。
- 有 BGA 只做 AOI 不做 X-Ray，空洞和桥连到 FT 才偶发。
- 省 SPI，钢网堵孔靠回流后 AOI 补——根因在印刷，返修率虚高。
- 换钢网版本不重做 SPI/AOI 程序，整批同一类缺陷。
