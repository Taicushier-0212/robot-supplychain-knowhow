# 电源模块

**大类：** [电子器件](./README.md)

## 1. 是什么

从 PACK 到母线、逻辑电的变换：预充、DCDC、滤波、配电。不是电芯本身（见 [能源](../05-energy/README.md)）。

## 2. 在机器人里干什么

多轴同时峰值时的能量缓冲、低压逻辑电、制动回馈路径。

## 3. 选型必须冻结

- [ ] 输入电压范围、输出路数与电流
- [ ] 预充、防反接、短路保护
- [ ] 再生能量去哪（电容 / 电阻 / 回电池）。电容种类见 [电容](./capacitors.md)
- [ ] 效率、散热、体积

## 4. 配套关系

按全身关节峰值电流之和做最坏情况，而不是按平均行走电流。母线插头的持续电流以规格书为准，XT30 名字里的数字不是安培。见 [XT30（2+2）](./connectors/xt30.md)。

## 5. 验收要点

空载电压、带载跌落、保护动作、温升。

## 6. 已知坑

- 单轴测试电源够，全身起立瞬间欠压保护。
- 回馈没有路径，下楼梯驱动报过压。
