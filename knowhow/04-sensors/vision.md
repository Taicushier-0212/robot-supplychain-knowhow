# 视觉

**大类：** [传感器](./README.md)

RGB、双目、深度、线激光等。镜头、触发、接口与线长一起冻；接口决定能不能装进头舱、过不过得了活动关节。

## 在机器人里干什么

导航、抓取、遥操作画面、部分建图。和 [算力 / 主控](../03-electronics/compute.md)、头部机构、[线束](../03-electronics/harness.md) 同一套冻结，不要相机先买、线后补。

## 接口怎么分

| 接口 | 适合 | 别默认 |
|---|---|---|
| **MIPI CSI** | 板到板很短、核心板原生相机口 | 过关节长线、反复弯折 |
| **USB3** | 样机外挂、短线调试 | 长活动段、强 EMI 旁；掉帧当算力不够 |
| **网口相机** | 远距、多机交换机 | 忘了带宽、供电（PoE）与同步 |
| **GMSL（+ FAKRA 等）** | 数米级、活动、车规式相机串行 | 只写「GMSL」不写 SerDes、线、座子 |

GMSL 的座子、线、芯片代数见 [GMSL 连接器](../03-electronics/connectors/gmsl.md)。

## 选型必须冻结

- [ ] 分辨率、帧率、视场、深度范围（若有）
- [ ] 接口类型；若 GMSL：代数、SerDes 料号、连接器型号、线长与是否 PoC
- [ ] 同步触发、曝光；多相机是否共触发
- [ ] 镜头固定方式、标定板流程；批次是否允许换镜头
- [ ] 功耗与散热；头舱温升
- [ ] 安装孔、外径、出线方向；活动段弯曲半径

## 配套关系

头部运动时的走线见 [线束](../03-electronics/harness.md)。GMSL / USB / 网口的插头见 [接插件](../03-electronics/connectors/README.md)。主控解串与 MIPI 通道见 [算力 / 主控](../03-electronics/compute.md)。

批次镜头差会导致标定不能复用。

## 验收要点

出图、目标帧率下丢帧、深度空洞、固定安装下标定重投误差；活动走线后再测一遍。

## 已知坑

- 只看分辨率，长线 USB 上掉帧。
- 镜头批次差，标定无法复用。
- 结构按 USB 开孔，到货 GMSL FAKRA。
- GMSL 与动力线共束，电机一用力就花屏。
