# 电芯

**大类：** [能源](./README.md)

单体锂电是 PACK 的积木。外形、化学体系、容量和放电倍率没冻之前，不要先锁 PACK 外壳和报价。消费级「高容量」电芯不要默认当动力循环用——人形峰值电流和行走续航要一起算。

## 在机器人里干什么

PACK 内部一颗颗串并联起来。选型看三件事：关节峰值能不能扛住压降、整机续航够不够、重量和体积装不装得下。只报「多少度电」不够下单。

电芯定了，BMS 保护阈值、镍带/汇流排截面、结构盒体的膨胀与隔热才跟得上。换芯等于换半个 PACK。

## 常见形态

| | **圆柱** | **软包** | **方壳** |
|---|---|---|---|
| 外形 | 金属圆筒，型号常按直径×高度命名 | 铝塑膜封装，可压扁 | 铝/钢棱柱壳 |
| 优点 | 规格成熟、散热路径清楚、供应商多 | 空间利用率高、形状好塞 | 成组规整、机械强度好 |
| 代价 | 圆柱间隙占体积；要焊点/支架 | 怕刺破、膨胀要预留；夹具要求高 | 单颗重、定制周期长 |
| 人形常见用法 | **18650 / 21700** 动力圆柱最常见 | 薄机身、不规则空腔 | 大容量躯干仓，样机阶段少见 |

下文圆柱按直径×高度叫：**18×65 → 18650**，**21×70 → 21700**。数字是名义尺寸，公差和正负极帽高度以数据手册为准，结构开孔不要按整数硬切。

## 18650

直径约 **18 mm**，高度约 **65 mm**（含正极端子时以手册总高为准）。消费电子和电动工具里用了很久，供应链成熟，牌号和倍率档都多。

### 它是什么量级

同一代化学体系下，常见能量型大约 **2.5–3.5 Ah** 一档，功率型容量往往更低、持续/脉冲放电更高。标称电压多在 **3.6–3.7 V**（磷酸铁锂另算，平台更低）。具体以该型号数据手册为准，不要拿「某电商 3500 mAh」当动力芯冻结值。

重量大致 **40–50 g** 一颗。PACK 里还要加支架、镍带、隔热和 BMS，整包克重不能按电芯裸重线性外推。

### 适合什么时候用

- 需要成熟供应、多货源、便于小批量打样和替换验证
- 总能量不大，愿意用更多串并联把峰值电流摊开
- 结构已经按 18 mm 栅格开好模具/支架，改 21700 代价高

### 要注意什么

- **串联颗数多**：同样电压平台，18650 往往比 21700 用更多颗。焊点、采样线和一致性管理都变复杂。
- **间隙多**：圆柱之间的三角空隙要靠支架和灌胶/隔热填，体积效率通常低于同代 21700。
- **倍率口径**：工具类高倍率芯和笔记本能量芯不是一类货。关节峰值按「持续放电」选型会在启动瞬间掉压保护。

## 21700

直径约 **21 mm**，高度约 **70 mm**。相对 18650，单颗体积大约大 **1.5 倍** 量级，同代化学下容量和能量通常更高，电动车和一部分机器人 PACK 已把它当默认圆柱。

### 它是什么量级

常见能量型大约 **4–5 Ah** 一档（视化学与倍率），功率型同样会拿容量换放电能力。标称电压口径与同类化学的 18650 接近，**不要和 18650 混串**——内阻、容量、老化曲线不一致，BMS 很难压住。

重量大致 **60–70 g** 一颗。单颗更重，但同样 Wh 常用更少颗，整包互连可能更简单。

### 适合什么时候用

- 躯干/背包仓希望少颗数、少焊点，把一致性风险压下去
- 同体积预算下想抬能量或抬放电余量
- 新建 PACK，支架和外壳还没按 18650 定死

### 要注意什么

- **直径和高度都大**：旧 18650 支架、端板、线束长度不能直接复用。
- **热更集中**：单颗能量高，局部温升和热失控隔离要按 21700 栅格重做，不能只改孔径。
- **货源分层**：消费「高容量 21700」和动力循环芯仍是两条供应链。样品好看、小批换牌，和 18650 是同一类坑。

## 18650 和 21700 怎么选

| 判据 | 更倾向 18650 | 更倾向 21700 |
|---|---|---|
| 结构现状 | 已有 18 mm 支架/模具 | 新开 PACK、可按 21 mm 布 |
| 颗数与焊点 | 能接受更多串并联 | 想少颗、少互连 |
| 体积效率 | 次要，或仓体细碎 | 同仓多塞 Wh |
| 供应策略 | 要成熟多货源、易打样对比 | 锁定动力圆柱主流规格 |
| 峰值电流 | 用并联摊电流也可 | 单颗倍率余量更大时更省并联 |

经验口径（不是公式）：同样化学代际，**21700 常用更少颗达到相近能量**；**18650 用并联补电流更灵活，但管理点更多**。最终用「整包重量、体积、峰值压降、循环目标」四件事一起算，不要只比单颗 mAh。

两种尺寸 **不要在同一串联支路混用**。并联支路若必须过渡，也要同型号、同批次策略，并写进冻结清单——默认禁止。

## 化学体系（选型时先分清）

圆柱尺寸只是外壳。同样是 21700，三元高能量、三元高功率、磷酸铁锂，放电和安全边界完全不同。

| 常见说法 | 选型时盯住 |
|---|---|
| 三元（NMC/NCA 等） | 能量密度高；热与过充更敏感；注意循环和高温口径 |
| 磷酸铁锂（LFP） | 平台电压更低，同样电压要更多串联；循环和热稳定性往往更好，低温与能量密度要单独验 |
| 「动力 / 高倍率」 | 持续与脉冲放电、温升、循环衰减曲线 |
| 「能量型」 | 容量好看，关节峰值未必扛得住 |

冻结时写化学体系 + 型号，不写「进口圆柱」这种空话。

## 选型必须冻结

- [ ] 形态：圆柱 / 软包 / 方壳；圆柱则冻 **18650 或 21700**（或其它明确型号尺寸）
- [ ] 化学体系、标称电压、容量；持续放电与峰值（脉冲）放电及允许时间
- [ ] 内阻口径、循环寿命（次数 + 截止条件 + 温度）
- [ ] 工作与存储温度；最大充电倍率与策略
- [ ] 重量、外形公差、正极结构（是否带帽/垫片）
- [ ] 品牌与型号是否允许替代；**禁止到货换芯**是否写进合同/检验规范
- [ ] 串并联拓扑（SxP）与目标电压/容量；是否禁止混型号混批次

## 配套关系

- [PACK / BMS](./pack.md)：保护阈值、采样、均衡按这款芯；换芯就重标 BMS。
- 结构盒体：按电芯栅格预留膨胀、隔热和排气路径；18650/21700 支架不通用。
- [电源模块](../03-electronics/power.md)：欠压、预充、峰值电流与电芯放电曲线对齐。

## 验收要点

- 外观：鼓包、漏液、极柱损伤、热缩膜破损
- 电压、内阻抽检；同批次离散度
- 抽测持续/脉冲放电是否达到冻结值（或厂家出厂报告 + 抽检复核）
- 到货型号/批次与订单一致；禁止无记录换牌

## 已知坑

- 只锁容量不锁放电倍率，关节峰值一来就欠压保护。
- 样品一套芯，小批换牌不通知，BMS 参数还按旧芯。
- 18650 支架强改塞 21700，或两种尺寸混串，一致性与热设计一起爆。
- 把消费级高容量芯当动力循环芯用，跌落、循环和高温口径都不成立。
- 结构按整数 18/21 mm 开孔，忽略总高和正极帽公差，盖不上或顶变形。
