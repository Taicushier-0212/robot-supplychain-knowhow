# 灵巧手

**大类：** [末端](./README.md)

## 1. 是什么

多自由度末端，电机或腱绳驱动，可选触觉。是演示和抓取能力的门面，也是协议和力控最容易低估工期的模块。在库型号的参数对照见 [选型对照](./selection.md)。

## 2. 在机器人里干什么

抓取、操作。自制仅在差异化明确时做；默认外购整手或套件。

## 3. 选型必须冻结

- [ ] 主动自由度、总自由度（欠驱动两个都冻）、负载、开合速度、自重
- [ ] 驱动方式（电机 / 肌腱）与可维修性
- [ ] 力控 / 触觉是否必须
- [ ] 通信、供电、手腕法兰
- [ ] 耗材：指面、腱绳更换周期

## 4. 配套关系

手腕法兰与小臂关节尽量少转接，转接会掉刚度。触觉见 [触觉](../04-sensors/tactile.md)。控制周期要进全身调度。

## 5. 验收要点

枚举、各自由度运动、限位、异常发热、SDK 示例能跑。

## 6. 已知坑

- 只看自由度数字，没有抓取场景清单。
- 手腕二次转接，刚度变差。
- 没有备件策略，一根腱绳断了整手停线。
