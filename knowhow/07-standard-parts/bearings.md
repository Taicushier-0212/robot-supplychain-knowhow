# 轴承

**大类：** [标准件](./README.md)

关节里轴承选错，看起来像减速机坏了、编码器跳、末端晃。谐波输出端、转台、中空关节法兰，最常拿下面几类互相顶替——**不能按外径差不多就换**。

口头「接触式轴承」不是标准分类名：多半指 **角接触球轴承**（有接触角、能吃轴向/弯矩组合），和深沟球、交叉滚子对比时这么叫。下文按标准叫法写。

## 一张表先分清

| | **交叉滚子** | **角接触球**（常被叫接触式） | **四点接触球** | **薄壁球** | **深沟球**（对照） |
|---|---|---|---|---|---|
| 滚动体 | 圆柱滚子，相邻滚子轴线 **交叉 90°** | 球，接触角常 15°/25°/40° | 球，滚道呈「尖拱」，一点可双向轴向 | 球，截面很薄的深沟或角接触系列 | 球，接触角 ≈ 0 |
| 一套能扛什么 | 径向 + 双向轴向 + **倾覆力矩** | 径向 + **单向**轴向（成对才双向/弯矩） | 径向 + **双向**轴向；弯矩能力一般弱于交叉滚子 | 看系列：有的近似深沟，有的是薄壁角接触 | 主要径向；轴向能力弱 |
| 刚度 / 晃 | **高**，关节输出端常用 | 单套一般；成对预紧后高 | 中等；预紧后可，但滚子线接触仍更刚 | 薄 → 截面刚度低，别指望扛大弯矩 | 一般 |
| 转速 | 偏低 | 可以很高 | 中高，看保持架 | 中高（轻载） | 高 |
| 摩擦 / 热 | 相对大 | 相对小 | 四点同时接触时摩擦偏大 | 轻载时小 | 小 |
| 轴向占位 | **很薄**一张就能当「转台」 | 单套薄；成对要两套厚度 | 一张可双向，轴向省 | 极薄、大中空 | 薄 |
| 机器人里 | 谐波输出、关节法兰、转台 | 电机端、丝杠、成对主轴式关节 | 中空回转、轻载双向轴向、部分转台替代 | 中空走线、轻载旋转、编码器端 | 电机、铰链、轻载支承 |
| 别拿去 | 当超高速电机轴承 | 单套顶谐波输出弯矩 | 当交叉滚子硬扛倾覆 | 当交叉滚子用 | 当输出端主轴承 |

## 1. 交叉滚子轴承（Crossed Roller）

滚子在滚道里 **隔一个转 90°**：一套轴承里同时有「立着的」和「躺着的」滚子，所以 **一个套圈组合** 就能吃径向、轴向和倾覆力矩。

- **为什么关节爱用：** 谐波柔轮输出、一体化关节法兰要薄、要刚、要中空——交叉滚子一张顶「两套角接触对研」的许多事。  
- **要冻：** 型号（如 RU/RB/RE/CRB 等系列逻辑不同：内圈分半还是外圈分半、有无安装孔）、游隙或预紧、许用弯矩、润滑。许用弯矩见 [谐波额定](../01-joint-modules/reducer/harmonic/ratings.md)。  
- **坑：** 外径像薄壁球就换过去 → 末端晃、编码器跳，却去换谐波。侧向力/弯矩超许用，先打轴承。转速和发热按样本，别按深沟球习惯狂转。

装配：过盈、轴向压紧、法兰平面度按样本；歪着压会把滚子棱边啃坏。

## 2. 角接触球轴承（Angular Contact）——口头「接触式」

球与滚道有 **接触角**：轴向力经接触角分解，单套主要吃 **一个方向** 的轴向力。要双向轴向或刚度，通常 **成对**（背对背 DB、面对面 DF、串联 DT）并加预紧。

- **和交叉滚子比：** 高速、低摩擦更擅长；要同等抗倾覆，往往要两套 + 隔圈 + 预紧，轴向更长、装配更敏。  
- **机器人里：** 无框电机端盖轴承、丝杠支撑、需要高转速的输入侧；输出端主承弯矩仍多见交叉滚子或厂家集成轴承。  
- **要冻：** 接触角、配对方式、预紧等级、游隙、密封。只写「角接触」不下配对方式 = 没冻。

「接触式」若对方指 **接触式密封**（唇密封），那是密封形式，不是轴承类型——和开式/非接触防尘盖不是一回事。

## 3. 四点接触球轴承（Four-Point Contact，常 QJ 类）

滚道截面做成尖拱，球与内外圈理论上可形成 **四个接触点**，使 **单列** 就能承受 **双向轴向力**，轴向占位接近一套深沟球。

- **擅长：** 中空轴、希望「一套搞定双向轴向」、转速要求高于交叉滚子、弯矩不大。  
- **不擅长：** 大倾覆力矩、高刚度转台——四点同时接触时自旋滑动多，摩擦和温升敏感；弯矩大时仍常要交叉滚子或角接触对研。  
- **和角接触：** 角接触单套单向；四点单套双向。不要用「都能吃轴向」混成一种。  
- **要冻：** 型号、轴向游隙/预紧、是否带隔离球或保持架形式。

## 4. 薄壁球轴承（Thin-Section）

按 **很薄的截面**（径向截面高度相对孔径很小）做的球轴承系列，常见深沟型、角接触型、四点型都有薄壁版。卖点是 **轻、中空大、占空间小**，不是「更抗弯」。

- **机器人里：** 中空走线关节里的轻载旋转、传感器座、轻载转盘、需要大孔径小截面的地方。  
- **坑：** 外径/孔径和交叉滚子接近，就当输出主轴承 → 截面柔，一点弯矩末端就晃。薄壁对座孔圆度、法兰平面度更敏感，壳体一软轴承跟着椭圆。  
- **要冻：** 系列（深沟 / 角接触 / 四点）、截面代号、游隙、材质（不锈钢等）、是否薄壁专用公差。

薄壁 **角接触** 仍要成对才吃双向；薄壁 **四点** 可单套双向，但弯矩能力仍远小于同外径交叉滚子。

## 5. 深沟球（对照，别漏）

最常见、便宜、高速好。主要扛径向，轴向只能吃很有限一点。电机、惰轮、轻载铰链默认可以；**谐波输出、关节主法兰不要只用深沟球顶弯矩**。

## 关节里怎么选（口头）

```text
谐波/关节输出法兰，要薄、要刚、要抗倾覆
  → 交叉滚子（或减速机已集成的输出轴承，问清还加不加）

要双向轴向、弯矩不大、想省轴向长度
  → 四点接触球；弯矩大仍回交叉滚子

高转速、可接受成对安装与预紧
  → 角接触球成对

大中空、轻载、截面必须极薄
  → 薄壁球（先分清深沟/角接触/四点）；不抗大弯矩

只是电机轴、轻载铰链
  → 深沟球通常够
```

减速机已集成输出轴承时：再外加一套可能过约束，也可能必要——以厂家接口图为准，不要「习惯性再套一个交叉滚子」。

## 选型必须冻结

- [ ] 类型：交叉滚子 / 角接触（含配对） / 四点 / 薄壁（哪种子型） / 深沟  
- [ ] 型号全称、孔径×外径×厚、游隙或预紧等级  
- [ ] 接触角（角接触）；安装方式 DB/DF/DT  
- [ ] 许用径向 / 轴向 / **弯矩**（输出端尤其）  
- [ ] 润滑（脂型号）、密封（开式 / 防尘盖 / 接触唇封）  
- [ ] 座孔公差与轴向压紧（按该轴承样本，不按「全厂 H7/g6」）  
- [ ] 是否与减速机集成轴承重复；允许品牌替代白名单  

## 配套关系

与谐波/关节座的过盈、轴向预紧、法兰平面度是结构工艺，不是到货再调。斜齿行星带来的轴向力要算进电机端与行星销轴承，见 [行星齿轮](../01-joint-modules/reducer/planetary/gears.md)。

## 验收要点

- 包装原装、型号打印、数量；禁止混批、禁止「同外形」杂牌顶精密交叉滚子。  
- 游隙/预紧等级与订单一致；成对轴承有配对标记的不要拆散混用。  
- 旋转手感：无异常沙哑、无卡滞；交叉滚子禁止干压歪装后还当合格。

## 已知坑

- 电商「同型号」杂牌，游隙和寿命不够。  
- 关节侧向力打轴承，当减速机坏了去换谐波。  
- 薄壁球或四点球顶交叉滚子抗弯矩，末端晃、编码器跳。  
- 单套角接触当双向用，反转打滚道。  
- 「接触式」采购单不写角接触还是密封形式，到货对不上。  
- 成对角接触不写 DB/DF 和预紧，装配师傅现场「拧到感觉差不多」。  
- 壳体孔不圆，薄壁轴承跟着椭圆，寿命断崖。
