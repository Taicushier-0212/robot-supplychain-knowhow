# 元器件 Knowhow

本目录按 **大类 → 小类 → 细分** 记元器件：它是什么、用在哪、选型冻什么、怎么验、踩过什么坑。

不维护供应商名录和联系方式。名录放在作业仓库。

## 分类树

```text
关节模组
  ├─ 减速机
  │    ├─ 谐波
  │    │    ├─ 结构（杯 / 帽 / 扁平）
  │    │    ├─ 额定 / 空程 / 寿命
  │    │    └─ 装配与润滑
  │    ├─ 行星
  │    │    ├─ NGW / NW / 星型…
  │    │    ├─ 齿轮与齿系
  │    │    └─ 行星架（笼式 / 悬臂）
  │    ├─ 摆线（含 RV）
  │    │    ├─ 结构（针摆 / RV 两级）
  │    │    ├─ 额定 / 刚度 / 寿命
  │    │    └─ 装配与润滑
  │    └─ 其它（蜗轮 / 锥齿 / 带 / 直驱）
  ├─ 无框力矩电机
  │    ├─ 内转子
  │    ├─ 外转子
  │    ├─ 槽极 / 极对数
  │    ├─ 绕线 / 磁钢 / 叠片
  │    ├─ 分瓣 / 整圆
  │    ├─ 装配 / 并联
  │    └─ 霍尔 / 温度
  ├─ 编码器
  │    ├─ 单编 / 双编 / 伪双编
  │    ├─ 磁编
  │    ├─ 电感编
  │    └─ 光编
  ├─ 驱动器
  ├─ 制动器
  └─ 一体化关节（买成套时）

结构件
  ├─ CNC 机加
  │    ├─ 铝（6061 / 7075 / ADC12）
  │    ├─ 镁（AZ31 / AZ91）
  │    └─ 钢（45 / 40Cr / 42CrMo / P20）
  ├─ 钣金
  │    ├─ 折弯与展开
  │    ├─ 板材
  │    └─ 连接（压铆 / 铆 / 焊）
  ├─ 型材
  ├─ 压铸
  ├─ 注塑
  ├─ 3D 打印
  └─ 表面处理
    ├─ 阳极（普通 / 硬质 / 导电）
    ├─ 发黑
    ├─ 喷涂（喷粉 / 喷漆 / 电泳）
    └─ 微弧氧化

电子器件
  ├─ PCB / SMT
  ├─ 线束
  │    ├─ AWG
  │    └─ 绝缘与镀层
  ├─ 接插件
  │    └─ XT30（2+2）
  ├─ 算力 / 主控
  └─ 电源模块

传感器
  ├─ 力 / 力矩
  ├─ 触觉
  ├─ IMU
  └─ 视觉

能源
  ├─ 电芯
  └─ PACK / BMS

末端
  └─ 灵巧手
       └─ 选型对照

标准件
  ├─ 轴承
  └─ 紧固件
```
