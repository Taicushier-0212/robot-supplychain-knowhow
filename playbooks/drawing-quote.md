# 采购怎么看图、怎么估价

采购不替结构签「设计对不对」，但必须从图纸里掏出：**这是什么件、哪几项在烧钱、询价包齐不齐、报价有没有漏项**。图没冻、版本不对，估价全是空转。门在 [G0–G5](../docs/gates.md)；发询价见 [RFQ](./rfq.md)；成本块见 [成本与交期](../docs/cost-leadtime.md)。

## 看图顺序（先抬头，再找贵的）

```text
1 图框 / 版本 / 料号     → 询的是不是这一版
2 材料 + 状态 + 毛坯形态 → 料费与能不能做
3 表面处理 / 热处理      → 外发二次，交期单列
4 关键尺寸与公差带        → 机床档次、检具、报废率
5 形位 / 基准 / 配合     → 装夹次数、三坐标、配磨
6 数量与工艺暗示         → 样品价 vs 小批价路径不同
```

不要一上来盯着某个倒角讨价；**版本和材料错了，后面白谈**。

## 图框上必须对上的

| 看什么 | 为什么 | 对不上时 |
|---|---|---|
| **图号 / 料号** | PO、IQC、仓库都认这个 | 停询价，回计划改 PR |
| **版本 / 日期** | 升版 = 旧报价作废 | 要新图再发 RFQ |
| **重量 / 比例 / 投影** | 估料、防看错孔 | 重量明显离谱先问结构 |
| **未注公差 / 粗糙度** | 厂按未注做；太严会当特殊公差报价 | 未注按哪本标准要写清 |
| **技术要求栏** | 探伤、试装、去毛刺等级、包装 | 漏了到货扯皮，报价也漏 |

电子件看 BOM + Gerber 版本，不看「一张装配示意」。线束看接插件型号和线号表。

## 重点：哪些在决定价格

采购用下面当 **报价拆解检查单**，不是自己当工艺员重算一刀。

### 材料

- 牌号 + 状态写全了吗？（`6061-T6`，不是「铝」；`45 调质`，不是「45 钢」）见 [材料](../knowhow/02-structure/materials/README.md)。  
- 板 / 棒 / 型材 / 铸件？同样零件棒料掏空和板料铣，料费和工时差一截。  
- 贵重或长周期料（7075、进口不锈钢、铜电极）要标红。  
- 利用率：大板开小件、厚板铣薄，料废率高——问厂按什么下料报价。

### 加工形态（先定工艺再比价）

| 图上信号 | 多半工艺 | 估价时多问 |
|---|---|---|
| 复杂腔、多面孔系、紧公差 | CNC | 装夹几次、几轴、要不要电极/线割 |
| 折弯展开、孔网、盒体 | 钣金 | 折弯道数、模具/工装、焊接还是铆接 |
| 标准槽孔、定长 | 型材 + 二次 | 型材规格是否市售，孔位是否二次加工 |
| 薄壁大件、拔模 | 压铸 / 注塑 | 模具费、模次、后加工 |
| 齿轮参数、硬度层深 | 齿轮工艺 | 滚/插/磨、热处理路径，见 [热处理](../knowhow/02-structure/materials/heat-treatment.md) |

同一张图，A 厂当「三轴铣」、B 厂当「五轴+线割」，单价不可比——先对齐工艺假设。

### 公差与形位（最容易把价打飞）

- **尺寸公差越紧 →** 慢走丝、研磨、恒温、检具↑。口头「全部 ±0.01」和关键配合 ±0.01、其余未注，价钱不是一档。见 [公差](../knowhow/02-structure/tolerances.md)。  
- **形位（同轴、垂直、平面、位置度）→** 装夹基准、三坐标时长、有时要配做。基准写在哪，决定检不检得起。  
- **配合代号**（`H7/g6`）按哪份轴承/销样本？写错孔系，厂按最严理解报价。  
- **粗糙度**（密封面、轴承挡肩 `Ra`）影响刀路和是否抛光。

采购动作：把「紧于未注」的尺寸和所有形位 **圈出来列清单**，询价时明示：这些是成本敏感项；能否放宽要回结构，不自己改图。

### 表面处理与热处理

- 阳极 / 喷涂 / 发黑 / 微弧：外发、排队、膜厚吃尺寸。见 [表面处理](../knowhow/02-structure/surface/README.md)。  
- 调质 / 渗碳 / 氮化：变形 → 往往要 **粗加工→热→精加工**，工时接近「做两次」。  
- 报价必须拆：机加 | 热处理 | 表面处理 | 运输包装；绑在一个「含所有」里最容易漏。

### 数量与批次

- 1～3 件：编程、装夹、检具摊销巨大 → 样品价。  
- 小批：问阶梯（10/50/100）和能否摊掉工装。  
- 模具 / 夹具 / 检具：NRE 谁出、能否抵后续批次，写进 RFQ。

## 怎么根据图纸估价（实操）

采购要的是 **可挑战的分解价**，不是自己报一个拍脑袋数给老板。

### 1. 先做「询价包」再问价

- [ ] 当前版本 PDF（或厂接受的格式）+ 料号版本  
- [ ] 材料、状态、表面、热处理原文摘出  
- [ ] 数量、要货日、含税口径  
- [ ] 成本敏感公差/形位清单  
- [ ] 必须打样还是可直接小批（见 [自制 vs 外购](../docs/make-vs-buy.md)）  

缺任一项，只可要 **意向价**，不能当正式比价。

### 2. 让供应商按块回价

对照 [成本拆分](../docs/cost-leadtime.md)：

```text
材料费
+ 机加 / 成型工时（含装夹、编程摊销）
+ 外发热处理
+ 外发表面处理
+ 检具 / 工装摊销（或 NRE 单列）
+ 包装物流
+ 利润与税（含税口径写死）
= 单价
```

只回一个总数：要求补拆，否则无法和另一家比，也无法判断「表面处理是否漏报」。

### 3. 自己做数量级 sanity check（结构件）

不替代厂报价，只抓离谱：

| 粗算 | 怎么想 |
|---|---|
| 料费下限 | 外轮廓体积 × 密度 × 牌号单价 ×（1.2～2 利用率视工艺） |
| 机加 | 去除体积大、型腔深、薄壁 → 工时长；孔系多面 → 装夹次数↑ |
| 紧公差项数 | 每多一项要三坐标/配磨的，单价台阶往上跳 |
| 二次外发 | 阳极/热处理往往按批 + 天排队，不是「加工日 +1」 |

料费都盖不住的报价 → 疑漏材料或偷换牌号；料费很小但总价夸张 → 盯工时与公差假设。

### 4. 比价时对齐假设

两家差 30%，先问是否同一版图、同一材料状态、是否含表面处理、公差是否按未注还是全按最严、是否含税。对齐后再谈砍价。见 [原则 · 比价](../docs/principles.md)。

### 5. 估价结论怎么写（给内部）

```text
版本：…  数量：…
工艺假设：CNC 三轴 / 含阳极 Ⅱ 级 / 调质…
敏感项：同轴 φ0.02、轴承孔 H7…
报价区间：A …  B …（含税）
风险：热处理变形后精孔、阳极吃孔径
建议：打样 / 直接小批；待结构确认是否放宽 …
```

不要只丢一个「大概 XX 元」。

## 采购看图时不要做的事

- 自己改公差「先便宜做出来」。  
- 用上版图询价、这版图下单。  
- 接受「按实物打样、图仅供参考」还当正式 PO 依据。  
- 把目标价倒逼未冻规格（铁律）。  
- 替 IQC 保证「这个公差厂肯定做得出来」——那是 [工艺工程 / DFM](../docs/process-engineering.md) 和首件的事。

## 和职位咬合

| 角色 | 对图纸 |
|---|---|
| 结构 / 电气 | 冻规格、答放宽 |
| 工艺工程 | DFM、工艺路线是否报价假设成立 |
| **采购** | 抽成本项、组 RFQ、拆价比价、PO 锁版本 |
| IQC | 按 **PO 绑定的那一版图** 判定 |

## 已知坑

- 图框版本对了，技术要求栏的探伤/试装没读，到货加钱或不合格。  
- 只比机加价，阳极和热处理到后期才「另算」。  
- 未注公差厂按宽做，IQC 按心里严的收 → 批量 NCR。  
- 样品编程费没说清是否抵批量，小批价突然不降。  
- 钣金按展开面积估，忽略折弯道数和焊接。  
- 齿轮/硬齿面按软齿机加报价，硬度层深没进价。  
- PDF 模糊、无尺度的轴测图拿去询价，各厂理解不同。
