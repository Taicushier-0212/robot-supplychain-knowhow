# 不合格 NCR

不合格不消失，必须留记录。总图见 [最小闭环](../docs/ops-loop.md)；判定口径见 [质量](../docs/quality.md)。

| Field | Value |
|---|---|
| NCR # | `NCR-YYYYMMDD-001` |
| 关联 PO / 料号 | |
| 等级 | L1 / L2 / L3 |
| 缺陷描述 | |
| 处置 | 返工 / 退换 / 让步 / 报废 |
| 关闭证据 | 纠正说明 / 影响批次 / 是否改检规 |

## 路径

| 路径 | 何时用 |
|---|---|
| 返工/挑选 | 缺陷可在厂内或供应商处消除 |
| 退货换货 | 无法用或供应商责任明确 |
| 让步接收 | 不影响安全/接口；必须书面、限批次；L3 禁止 |
| 报废 | 无使用价值；成本记到对应 PO |

## 关闭与复盘

- 无证据不关 NCR（供应商一句「已注意」不够）。  
- 关闭人按 [授权矩阵](../docs/ops-loop.md#授权矩阵初期)：SQE 执行，供应链拍板；缺岗按 [RACI 代签](../docs/raci.md)。  
- 同一供应商重复 L2/L3 → 降权或暂停新单，在 G5 回写评分。  
- 可复用结论用 [卡片模板](../templates/knowhow-card.md) 写进对应 knowhow；没有复盘结论的 PO 不算 G5 完成。

## 8D 报告是什么

8D 是供应商交回来的**纠正措施报告**，按八步写。NCR 是我们自己的不合格单；8D 是厂对这张单的答复。有 NCR 不等于自动要一份 8D。退货、换货可以先走完，8D 问的是下一批还会不会同样错。

L2/L3、重复发生、图号或版本做错、不良已经流到装配，要 8D。L1 的单颗外观、数量短装，把处置写进 NCR 即可，不必凑一份八步。等级见 [质量口径](../docs/quality.md)。

| 步 | 要写清什么 | 不算数的写法 |
|---|---|---|
| **D1** 小组 | 供应商谁负责，我们 SQE 谁对接 | 只写一个销售名字 |
| **D2** 问题 | 料号、PO、批次、现象、数量、在哪发现的 | 「质量不稳定」 |
| **D3** 围堵 | 在制、在途、库存、已上线的怎么隔离 | 把围堵写成永久对策 |
| **D4** 根因 | 为什么做成这样，为什么没检出来；附证据 | 「员工疏忽」「加强责任心」 |
| **D5** 选定措施 | 改工艺、改检具或改图的哪一条，小批验证有效 | 还没做就写「将培训」 |
| **D6** 实施 | 作业指导书和现场已经改了 | 只有会议纪要 |
| **D7** 预防 | 同类件、别的线会不会再犯；检验项要不要加 | 只改这一批 |
| **D8** 关闭 | 下一批的检验记录能对上 D5 | PDF 交到就关 NCR |

SQE 收报告，采购不代判根因对不对。关 NCR 要看到 D6 已经发生，并且下一批（或约定的验证批）按 D5 的方法复检过。见 [职位](../docs/roles.md) 里 SQE 和 IQC 的分工。
