# 询价 RFQ

只对 **G1 已审核** 的需求发询价。关联申购单号。发之前怎么从图纸抽出成本项、拆价比价，见 [采购看图与估价](./drawing-quote.md)。

## 发出前

- [ ] 料号 / 版本与图纸一致  
- [ ] 材料、表面处理、数量、目标交期写死  
- [ ] 成本敏感公差 / 形位已列出（或已确认按未注）  
- [ ] 含税/未税口径统一  
- [ ] P0 计划问 ≥2 家  
- [ ] 要求供应商按材料 / 机加 / 二次处理拆价（结构件）  

## 请供应商确认

- 单价与阶梯、MOQ、交期  
- 样品费 / NRE  
- 付款与账期  
- 质保、不良处理  
- 图纸保密  

## 比价

不只看单价：交期、MOQ、样品费、账期、不良政策、沟通响应。  
升版后旧 RFQ 作废。
